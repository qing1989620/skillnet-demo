  技术细节再查报告第 5 章「关键发现」与第 6 章「接入路径」。


【二、跑起来看演示】

  Windows        双击 start.bat
  macOS / Linux  在终端执行：bash start.sh

  脚本会自动挑选 Python 解释器、安装缺失依赖、检查密钥、启动服务并打开浏览器。

  访问地址：
    http://127.0.0.1:8848            汇报演示页（对话式入口，推荐从这里开始）
    http://127.0.0.1:8848/dashboard  完整 Dashboard（技能库 / 关系图 / 实验结果）

  演示页用法：在对话框输入任何科研问题（不限领域），回车发送。
  系统自动完成五阶段闭环并逐段动画展示：
    1 检索对比（BM25 / Hybrid / Fabric 三档同题对照）
    2 LinUCB 策略选择（候选池按历史反馈排序：预测收益 + 探索奖励）
    3 任务级路由与依赖编排（DAG）
    4 技能驱动执行与盲评（主客观双线指标）
    5 反馈回流与技能蒸馏（本次奖励改变下一次排序，新技能回流库）
  每轮回答附真实成本与 Token 记账。

  关闭命令行窗口即停止服务。
  环境要求：Python 3.10 或更高（唯一硬性依赖）。
  首次运行需要联网安装 5 个 Python 包，大约 30 秒。


【三、需要 API 密钥吗？】

  不需要密钥也能看到大部分内容：

    可用     技能库浏览 ｜ 三档检索对照 ｜ 技能关系图（交互式可视化）
             三组实验的结果面板 ｜ 跨框架导出（Claude Code / ADK / Cursor / Gemini）
             策略选择排序（LinUCB 纯本地计算，不需要密钥）

    需密钥    Fabric 的 LLM 重排（缺密钥时显式降级，页面标注原因）
             技能驱动的 Agent 执行与盲评
             技能蒸馏 / 变异 / 交叉 / 再生成 ｜ 对话式全链路演示

  配置方法：编辑本目录下的 .env 文件，填入你的 DEEPSEEK_API_KEY，然后重启。
  （包内附 .env.example，复制改名即可。）

  用的是 DeepSeek 开放平台，按量计费。
  本项目全部实验（3 组、数百次调用）合计约 5 元，单次演示不到 1 毛钱。


【三点五、如果要开放给别人访问】

  默认只监听本机（127.0.0.1），别人访问不到。

  如果确实要开放给同事访问，请先设置一个访问令牌：

    Windows        set SKILLNET_TOKEN=自定义口令
    macOS / Linux  export SKILLNET_TOKEN=自定义口令

  设置之后，会花钱或会写盘的接口（任务路由 / Agent 执行 / 技能进化 /
  一键演示 / 跨框架导出）需要带上请求头 X-SkillNet-Token 才能调用。
  只读接口不受影响。

  不加这一步的话，任何能访问到你机器的人都能无限消耗你的 API 额度，
  并往技能库里写东西。

【五、常见问题】

  Q：提示「未找到 Python」？
  A：到 python.org 安装 Python 3.10+，安装时务必勾选 "Add Python to PATH"。

  Q：依赖安装失败？
  A：手动执行  pip install -r requirements.txt
     若在受限网络下，可先用国内镜像：
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

  Q：8848 端口被占用？
  A：python run.py --port 9000

  Q：想复跑实验、验证报告里的数字？
  A：python bench/run_bench.py all
     注意会真实调用 API 并产生费用。只想看结果的话，直接读 out/exp*.json
     或在 Dashboard 的「实验结果」页查看，不必重跑。

  Q：技能定义在哪、怎么改？
  A：每个技能是一个目录，入口是 seed/skills/<技能名>/SKILL.md。
     格式遵循 agentskills.io 规范，与 Claude Code / Cursor / Google ADK 通用。

  Q：演示后技能库变多了，想恢复初始状态？
  A：删除 data/library.json 后重启即可回到 51 个种子技能。


【六、这个包想说明什么】

  一句话：立理 S1 已经有 300+ 科研工作流与大量 Skills，
  本原型补的是它们上面的一层「运维能力」——
  把技能组织成网络、检索到对的那个、按历史反馈选择、
  并从每次执行的反馈中持续进化。

  与已有工作（SkillNet / COBRA-Skills / Repo-To-Skill / EvoScientist 四篇）
  的逐项对照见 docs/references.md；
  证据分级（Demonstrated / Supported / Preliminary / Not yet validated）
  说明文档第三节有完整标注。
