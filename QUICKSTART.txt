SkillNet / S1 科研能力生态 - 完整交付版
更新日期：2026-10-13

1. 获取完整版本
   git clone --branch main https://github.com/qing1989620/skillnet-demo.git skillnet-demo-complete
   cd skillnet-demo-complete
   python tools/verify_delivery.py --strict-runtime
   只有 ok=true 且 differences=[] 才表示初始产品文件完整。

2. 安装与启动
   需要 Python 3.11+。
   Windows：双击当前目录的 start.bat。
   macOS / Linux：bash start.sh。
   手动：python -m pip install -r requirements.txt
         python run.py --no-browser
   默认：http://127.0.0.1:8848
   端口占用时会明确退出，不会把旧服务当成新版本打开。
   先关闭旧服务，或：python run.py --port 9000

3. 核对版本与数据
   python run.py --version
   http://127.0.0.1:8848/api/health
   完整版标记：2026.10.13-complete.16
   首页版本：2026-10-13.complete.16
   初始技能快照：1,881 = 76 种子 + 1,769 社区 + 36 已有演化。
   新任务后运行数据可以变化；文件清单区分正式文件与可变运行库。

4. 页面入口
   /          产品总览、能力球体、七阶段与交付依据
   /chat      科研对话工作台
   /graph     球体能力网络
   /runs      运行中心
   /dashboard 内核实验室
   /docs      接口文档

5. 模型与联网
   将 .env.example 复制为 .env，并填写自己的 DEEPSEEK_API_KEY。
   密钥不是源代码，不随公开仓库分发。
   无密钥也能浏览、基础检索、查看公开运行和冻结实验。
   新建完整模型任务及 Fabric 重排需要模型服务。
   同版本多语言语义模型已随仓库携带，首次启动自动离线恢复。
   /api/health 的 encoder.kind 应为 dense-onnx；详见技术部署文档。
