内核实验室

立理 S1 科研技能生态原型 · Skill Retrieval / Evolution / RL

面向 立理 S1 的 Agent 与科研工作流，构建可接入的技能运维层： 技能以统一本体组织（技能卡 · 类型化关系 · 五维质量评估）， 通过混合 RAG 检索被路由，通过上下文老虎机被选择性评估， 并通过蒸馏 / 变异 / 交叉持续进化。目标不是再造一个技能库， 而是回答一个问题：当技能规模变大，Agent 还能不能找对、用对、并且越用越好。

技能关系图 Skill Relation Graph

节点为技能，连线为类型化关系（依赖 / 组合 / 相似）。节点半径表示实测平均奖励，朱红色为演化产生的技能。

全链路演示 End-to-End

选一条任务，一次跑完整条链路：技能检索与策略选择 → 任务级技能 Wiki 路由与依赖编排 → 生成方案 → 多步代码执行与修复 → 产物分层验收 → 有证据才反馈和准入。 完整执行链创建可回放的 Run；「研究方案对照」保留三档检索与单步实验，单步通过不代表整条方案完成。

Fabric 式任务级路由 Task Wiki Routing

方案对照评价研究方案；真实执行会创建独立运行记录并交付实际文件。
