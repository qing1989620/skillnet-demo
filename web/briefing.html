PROBLEM · 为什么需要它

Agent 的能力不会自己变好

三个所有 Agent 产品都会撞上的问题，来自顶会论文的实证，不是我们的想象。

技能找不准

前沿 Agent 在真实社区技能池上做检索，完整度只有个位数到 30%；关键词检索基本不可用。

SkillNet 论文 · SkillNet-Gym 实测（浙大 / 阿里 / 蚂蚁 / 腾讯，arXiv 2603.04448）

编排会崩塌

即使检索到技能，要求按依赖关系组织成工作流时，硬任务分数进一步大幅下滑。

同上 · "Frontier Agents Exhibit Weak Skill Composition Ability"

能力只进不出

AI 科学家系统是静态流水线，反复走同一条死路；把经验蒸馏成可复用技能，MLE-bench 提升 134.3%。

EvoScientist（华为）/ Repo-To-Skill（BAAI 等）实证
结论：Agent 时代缺的不是更强的模型，而是一层把「技能」管起来的基础设施—— 找得到、排得对、用得动、评得清、能进化。这就是 SkillNet-S1 要做的事。

DIFFERENTIATION · 凭什么说它更好

四种做法放在一起看

同一个任务、同一个模型，差别只在「技能怎么被用起来」。右侧三张卡是本项目的独有能力，点击可直接跳到真实产物。
能力裸模型提示词塞技能通用向量 RAGSkillNet（本项目）
技能组织方式无平铺文本向量库类型化关系图（90 条边）
检索无无（全靠上下文）单路向量三档：关键词 + 语义 + 关系图扩展
是否真的执行只输出文本只输出文本只输出文本沙箱真实运行 + 失败修复循环
产物验收无无无技能 verification 逐条验收（带证据）
选择策略无无无LinUCB + 反馈回流（下次排序会变）
技能进化无手工维护手工维护轨迹蒸馏 + 质量准入（库自己长）
效果如何证明无无无有/无技能对照实验 + dev/heldout 隔离
唯一：产物级技能验收 别的方案到「执行」就结束了。我们把技能里的 verification 变成逐条验收标准， 要求验收员引用产物中的具体证据、不得推测——未满足的如实标 FAIL。
实测证据：corr(dose,log10(dose))=0.7081，标注高度共线
唯一：检索会沿关系图补漏 关键词检索漏掉的技能，沿 90 条类型化关系边补回来。 同一份任务实测：BM25 召回 66.7% → Fabric 100%。
演示页第 1 阶段可直接看到「补回了哪几条」
唯一：反馈真的改变下次 本次任务的评分写回共享参数 θ，同领域技能的预测随之变化。 实测：一次任务后预测值 0 → 0.73，探索奖励同步衰减。
演示页第 6 阶段有「更新前 → 更新后」对比表
实测数字（同任务、同模型、同步骤，只改「技能怎么被用」）： 运行输出信息量 裸模型 1285 字 / 提示词塞技能 1510 字 / 契约模式 2217 字； 产物验收 前两者无标准、契约模式 2/3 条通过且逐条给出证据 （如「输出标注剂量与 log10 剂量高度共线」）。失败重试时，前两者只能盲试， 契约模式可以对照技能里记录的已知陷阱定位。
哪里不占优（不吹）：产物数量契约模式并非最多（实测 2 个 vs 提示词模式的 3 个）—— 它的优势在可验证性与约束落地，不在堆数量。另外当前只对方案中的一步做真实执行， 全流程分步执行尚未实现；沙箱面向可信代码，不是对抗性隔离。
和 Anthropic 官方 Agent Skills 的关系（诚实说明）： 官方标准解决的是「技能怎么打包、怎么被加载」，我们在此基础上补的是 技能怎么被选、怎么被执行、产物怎么被验收、库怎么自己变大。 我们的技能目录完全遵循 agentskills.io 规范，可直接导出给 Claude Code / Cursor / ADK 使用—— 不是替代，是补齐技能生命周期的后半段。

汇报脚本（3 分钟讲法，内部参考）
  1. 30 秒 · 问题：行业证据开场——前沿 Agent 在真实技能池上检索完整度只有个位数到 30%，编排硬任务崩塌（SkillNet-Gym）。这不是模型不够强，是缺一层技能基础设施。
  2. 60 秒 · 方案：指着架构图讲五段闭环；强调四篇论文各占一块，我们是唯一把闭环串起来并加治理层的。重点讲绿色虚线：实测奖励回流、新技能回流库。
  3. 90 秒 · 现场演示：选一个示例任务点「运行闭环」。Stage 1 指着表讲 Fabric 为什么补进了 BM25 漏掉的技能（trace 里有关系扩展证据）；Stage 2 讲 DAG 顺序；Stage 3 强调主客观分离；Stage 4 强调「这次演示本身就在给库加资产」。
  4. 30 秒 · 差异化：对照表扫一遍——选择策略、进化、治理、跨框架导出都是论文没有的；主动讲 held-out 治理（我们主动暴露了过拟合），体现科研诚信。
  5. 收尾：三阶段接入路径 + 「这套东西可以直接接到 S1 的 Agent 编排层上，Phase 1 两周就能出对比数据」。
