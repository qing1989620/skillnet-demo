PROBLEM · 为什么需要它

Agent 的能力不会自己变好

三个所有 Agent 产品都会撞上的问题，来自顶会论文的实证，不是我们的想象。

技能找不准

前沿 Agent 在真实社区技能池上做检索，完整度只有个位数到 30%；关键词检索基本不可用。

SkillNet 论文 · SkillNet-Gym 实测（浙大 / 阿里 / 蚂蚁 / 腾讯，arXiv 2603.04448）

编排会崩塌

即使检索到技能，要求按依赖关系组织成工作流时，硬任务分数进一步大幅下滑。

同上 · "Frontier Agents Exhibit Weak Skill Composition Ability"

能力只进不出

AI 科学家系统是静态流水线，反复走同一条死路；把经验蒸馏成可复用技能，MLE-bench 提升 134.3%。

EvoScientist（华为）/ Repo-To-Skill（BAAI 等）实证
结论：Agent 时代缺的不是更强的模型，而是一层把「技能」管起来的基础设施—— 找得到、排得对、用得动、评得清、能进化。这就是 SkillNet-S1 要做的事。

汇报脚本（3 分钟讲法，内部参考）
  1. 30 秒 · 问题：行业证据开场——前沿 Agent 在真实技能池上检索完整度只有个位数到 30%，编排硬任务崩塌（SkillNet-Gym）。这不是模型不够强，是缺一层技能基础设施。
  2. 60 秒 · 方案：指着架构图讲五段闭环；强调四篇论文各占一块，我们是唯一把闭环串起来并加治理层的。重点讲绿色虚线：实测奖励回流、新技能回流库。
  3. 90 秒 · 现场演示：选一个示例任务点「运行闭环」。Stage 1 指着表讲 Fabric 为什么补进了 BM25 漏掉的技能（trace 里有关系扩展证据）；Stage 2 讲 DAG 顺序；Stage 3 强调主客观分离；Stage 4 强调「这次演示本身就在给库加资产」。
  4. 30 秒 · 差异化：对照表扫一遍——选择策略、进化、治理、跨框架导出都是论文没有的；主动讲 held-out 治理（我们主动暴露了过拟合），体现科研诚信。
  5. 收尾：三阶段接入路径 + 「这套东西可以直接接到 S1 的 Agent 编排层上，Phase 1 两周就能出对比数据」。
