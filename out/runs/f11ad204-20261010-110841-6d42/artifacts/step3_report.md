# 科研复现审计报告（Step 3）

> **声明：本报告基于模拟数据（simulated data）完成，仅用于科研复现流程审计。**
> **所有阳性判定采用固定阈值 score ≥ 0.5，未在测试集上做任何阈值选择。**
> **本结果不代表临床有效性，不可用于任何医学诊断或真实模型性能结论。**

## 1. 数据来源与流程

本步骤读取前序产物 `cohort_audit.csv` 与 `heldout_metrics.csv`，不重新生成或修改数据。

- 清洗流程（Step 1）：按 `sample_id` 去重保留首次记录 → 识别跨 split 的 `subject_id` → 删除这些受试者全部记录 → 删除 `score` 缺失记录。
- 评估流程（Step 2）：仅使用清洗后的 test 行，固定阈值 `score >= 0.5` 判为阳性。

## 4. 数据泄漏风险

- **跨 split 受试者泄漏**：同一 `subject_id` 若同时出现在 train / validation / test 中，其记录会携带受试者层面的信息跨越数据划分边界。本流程已识别并删除全部跨 split 受试者的记录（共 1 名受试者、2 条记录），以阻断该泄漏路径。
- **重复记录泄漏**：重复 `sample_id` 若不去重，会人为放大某些样本权重。本流程保留首次记录，删除 1 条重复记录。
- **阈值泄漏**：若在 test 集上挑选阈值，会高估性能。本流程使用预先固定的阈值 0.5，未做任何测试集阈值搜索，也未计算 AUROC。

## 5. 复用边界

- 本审计仅适用于**本模拟数据集**的流程正确性验证，**不可外推**到任何真实临床数据、真实患者群体或真实模型性能评估。
- 清洗规则（去重、跨 split 删除、缺失删除）与固定阈值均为本次审计的约定，复用至其他数据集时需重新评估其适用性。
- 报告中的指标数值仅反映该模拟数据在固定阈值下的表现，**不代表临床有效性**，不得作为医疗决策依据。
