uppercase tracking-[0.18em] text-primary ">Editorial commentary</p><div class="prose prose-slate mt-2 max-w-none prose-a:text-primary"><p>The <strong>Crossref REST API</strong> is the programmatic counterpart to Crossref&#8217;s public <a href="/dictionary/term/crossref-doi">DOI</a> <a href="/dictionary/term/metadata" class="text-primary underline-offset-2 hover:underline" data-autolinked="true" title="Metadata — CASRAI Dictionary">metadata</a> search &#8212; the same free-text matching available at search.crossref.org is exposed as a queryable API, plus routes for journals, funders, members, licenses, prefixes, and content types.</p>
<h2>Core routes</h2>
<ul>
<li><strong>/works</strong> &#8212; the primary metadata route; supports <code>query.bibliographic</code> (free-text matching across titles, authors, ISSNs, and years, replacing the now-deprecated <code>query.title</code> parameter), filtering, and direct DOI lookup at <code>/works/{doi}</code>.</li>
<li><strong>/journals</strong>, <strong>/funders</strong>, <strong>/members</strong>, <strong>/licenses</strong>, <strong>/prefixes</strong>, <strong>/types</strong> &#8212; narrower routes for the corresponding metadata categories.</li>
<li><strong>Format transforms</strong> &#8212; e.g. <code>/works/{doi}/transform/application/x-bibtex</code> for a direct BibTeX record of a known DOI, an alternative to the content-negotiation route via doi.org itself.</li>
</ul>
<h2>Authentication and the polite pool</h2>
<p>No authentication or API key is required. Including a <code>mailto</code> query parameter, or a User-Agent header that identifies the calling tool and a contact email, routes requests to Crossref&#8217;s &#8220;polite pool&#8221; &#8212; a set of API machines reserved for identified, well-behaved callers &#8212; since this only applies over HTTPS. Response headers include rate-limit information (<code>x-rate-limit-limit</code>, <code>x-rate-limit-interval</code>).</p>
<h2>Frequently Asked Questions</h2>
<h3>Do I need a Crossref account to use the REST API?</h3>
<p>No &#8212; read <a href="/dictionary/term/access" class="text-primary underline-offset-2 hover:underline" data-autolinked="true" title="Access — CASRAI Dictionary">access</a> to metadata via api.crossref.org requires no account or key. Depositing or updating metadata (the separate <a href="/dictionary/term/deposit" class="text-primary underline-offset-2 hover:underline" data-autolinked="true" title="Deposit — CASRAI Dictionary">deposit</a>/registration workflow) does require a Crossref member account and credentials.</p>
<h3>Does the REST API cover DOIs registered by DataCite instead of Crossref?</h3>
<p>No &#8212; api.crossref.org only indexes DOIs Crossref itself has registered. DataCite-registered DOIs (common for datasets and software) are queried via DataCite&#8217;s own separate API.</p>
