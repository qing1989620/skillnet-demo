任务：我有一批不同剂量下的药物抑制率实验数据，想估计 IC50 并评估拟合质量与不确定性

加载技能：data-cleaning、eda-profiling、statistical-testing、scientific-visualization、estimator-robustness-audit ｜技能采纳率 100%

研究思路

以剂量-抑制率数据为输入，先做数据清洗与结构探查，再用四参数 logistic（4PL）或三参数 logistic（3PL）模型拟合剂量-反应曲线并估计 IC50，随后用 bootstrap 与残差诊断评估不确定性和拟合质量，最后用蒙特卡洛稳健性审计与出版级可视化交付可复现结果。

执行步骤（5 步）

S1读取原始剂量-抑制率数据，统一剂量单位（如 μM）、抑制率口径（0-1 或 0-100%），检查重复孔、缺失值与异常点，输出带审计日志的干净数据集。
调用技能 data-cleaning
关键参数
  • 剂量单位统一为 μM 或 log10(μM)，避免跨数量级拟合偏差
  • 抑制率统一为 0-1 小数，便于模型参数解释
  • 异常值判定用业务规则：抑制率超出 [0,1] 或剂量为负/零且无载体对照说明时标记
  • 缺失率 >20% 的剂量点单独标注，不直接删除
预期产出
干净数据表（列：dose、response、replicate、group）、清洗审计日志、数据字典
校验：清洗后主键唯一；审计日志可复现每一步；关键字段分布变化有解释；剂量-响应散点无系统性单位错位
S2对清洗后数据做单变量分布、分组对比与剂量-响应关系初探，确认是否单调、是否存在平台期、每组重复数是否足够。
调用技能 eda-profiling
关键参数
  • 按剂量分组计算均值、SD、n
  • 检查最低剂量抑制率是否接近 0、最高剂量是否接近 100%（用于判断 Bottom/Top 是否需固定）
  • 重复数 n<3 的剂量点标记为低置信
  • 共线性检查：log10(dose) 与 dose 不共存于同一模型
预期产出
EDA 报告、剂量-响应散点图、候选模型形式建议（4PL/3PL/固定 Bottom）
校验：分布图覆盖全部剂量点；组间样本量差异已标注；曲线形态支持所选模型形式
S3用非线性最小二乘拟合 4PL/3PL 模型，估计 IC50 及其标准误，并对模型参数做 Wald 检验与似然比检验比较嵌套模型。
调用技能 statistical-testing
关键参数
  • 4PL 公式：y = Bottom + (Top-Bottom)/(1+10^((logIC50-x)*HillSlope))
  • 若 Bottom 固定为 0 或 Top 固定为 100，用 3PL 并做 F 检验比较
  • 初始值：Bottom=min(y), Top=max(y), logIC50=median(log10(dose)), HillSlope=1
  • 显著性水平 α=0.05，多模型比较用 Bonferroni 校正 α'=0.05/k
预期产出
IC50 点估计、95% 置信区间、HillSlope、Top/Bottom、拟合优度 R² 与残差标准误
校验：参数收敛且标准误有限；残差无系统趋势；嵌套模型比较 p 值经校正后报告
S4对 IC50 估计量做 bootstrap 不确定性与蒙特卡洛稳健性审计：重采样估计 IC50 分布，检查收敛性与假设违反下的边界行为。
调用技能 estimator-robustness-audit
关键参数
  • Bootstrap 重复次数 ≥10000，重采样单位=独立实验批次/孔
  • 样本量梯度 n ∈ {10, 100, 1000, 10000} 用于收敛检查
  • α=0.05 双侧，多命题比较 Bonferroni α'=0.05/k
  • 随机种子运行前固定并写入日志，更换种子重跑确认方向不变
  • 反例边界：HillSlope→0（无响应）、HillSlope 极大（陡峭）、Bottom/Top 不可识别
预期产出
IC50 bootstrap 分布、95% CI、收敛曲线、泄漏审计报告、适用范围表
校验：收敛曲线斜率与理论 O(n^{-1/2}) 在置信带内一致；更换种子后结论方向不变；样本流与命题一一对应无重叠
S5绘制出版级剂量-响应曲线图：散点+拟合曲线+95% 置信带，标注 IC50 与置信区间、HillSlope、样本量。
调用技能 scientific-visualization
关键参数
  • x 轴 log10(dose)，y 轴抑制率 0-1 或 0-100%
  • 误差条为 SD 或 SEM，图注注明 n
  • 导出 PDF/SVG 矢量格式，字体 ≥7 pt，单栏宽度可读
  • 配色对色觉障碍友好（如 Okabe-Ito）
预期产出
矢量图 PDF/SVG、绘图脚本、自解释图注
校验：坐标轴与单位标注完整；误差条与样本量齐备；图为矢量且字号达标；IC50 标注与统计结果一致

风险与应对

  • 剂量-响应曲线未覆盖平台期导致 Top/Bottom 不可识别，IC50 外推不可靠——应对：检查最低/最高剂量抑制率，必要时固定 Bottom=0 或 Top=100 并报告为 3PL。
  • HillSlope 接近 0 或极大时 IC50 置信区间爆炸——应对：报告 profile likelihood CI 而非仅 Wald CI，并做 HillSlope 敏感性分析。
  • bootstrap 重采样单位错误（按孔而非按独立实验批次）导致 CI 过窄——应对：明确重采样单位，记录在审计日志，并用分层 bootstrap 验证。
  • 数据清洗阶段静默删除异常点导致选择偏差——应对：保留审计日志，异常点标记而非删除，做含/不含异常点的敏感性对比。
