# 数据字典与清洗审计说明

## 1. 文档目的
本文档定义 MathorCup 大数据竞赛所用数据集的字段口径、类型、缺失规则、异常判定与清洗审计轨迹。所有字段值均为**示意值，需真实数据验证**，不得直接用于最终结论。

## 2. 字段定义
| 字段名 | 中文含义 | 数据类型 | 单位 | 允许缺失 | 主键 | 取值/约束 | 清洗规则 |
|---|---|---|---|---|---|---|---|
| record_id | 记录唯一标识 | string | - | 否 | 是 | 非空、全局唯一 | 去重，保留首次出现 |
| event_time | 事件时间 | datetime | ISO8601 | 否 | 否 | 不晚于数据截止日 | 统一时区为 UTC+8 |
| group_id | 分组标识 | string | - | 否 | 否 | A/B/C 等 | 去除首尾空格 |
| feature_1 | 数值特征 1 | float | 无量纲 | 是 | 否 | 建议 [0, 100] | 超出 3 倍 IQR 标记为异常 |
| feature_2 | 数值特征 2 | float | 秒 | 是 | 否 | >= 0 | 负值置为缺失并记录 |
| category_1 | 类别特征 1 | category | - | 是 | 否 | 枚举 5 类 | 未知类别归为 Unknown |
| target | 预测目标 | float/int | - | 否 | 否 | 二分类 0/1 或连续 | 不参与清洗变换 |

## 3. 缺失值处理策略
- 缺失率 < 5%：数值特征用中位数填充，类别特征用众数填充。
- 缺失率 5%–30%：保留缺失指示变量 `feature_x_isna`，数值用中位数填充。
- 缺失率 > 30%：默认不进入基线模型，仅在 EDA 中报告。
- 所有填充操作必须记录到 `cleaning_audit_log.csv`。

## 4. 异常值判定
- 数值特征：采用 IQR 法，低于 Q1 - 3*IQR 或高于 Q3 + 3*IQR 标记为异常，不直接删除，生成 `is_outlier` 标记。
- 时间特征：早于 2000-01-01 或晚于数据截止日视为异常。
- 业务规则：如 `feature_2 < 0` 视为非法，置为缺失。

## 5. 清洗审计日志字段
| 字段 | 说明 |
|---|---|
| step | 清洗步骤编号 |
| field | 涉及字段 |
| action | 操作类型（fill/drop/clip/flag） |
| rule | 触发规则 |
| affected_rows | 影响行数 |
| timestamp | 操作时间 |

## 6. 防泄漏检查清单
- [ ] 目标变量未参与任何填充或编码。
- [ ] 训练集与测试集划分在清洗前固定，随机种子 42。
- [ ] 标准化/编码参数仅用训练集拟合。
- [ ] 缺失指示变量在训练与测试中定义一致。
- [ ] 时间序列任务按时间切分，禁止未来信息回填。

## 7. 可信度边界
本文档为方案级模板，字段名、阈值与规则均为**示意值，需真实数据验证**；实际竞赛中应以官方数据说明与赛题要求为准。
