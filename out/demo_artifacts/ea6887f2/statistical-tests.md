# 统计检验结果表与方法段落

> 说明：本文为方案级模板，所有数值均为**示意值，需真实数据验证**。

## 1. 检验流程
1. 正态性检验：Shapiro-Wilk（n<5000）或 Kolmogorov-Smirnov（n≥5000）。
2. 若 p>0.05，用 t 检验；否则用 Mann-Whitney U 或 Wilcoxon。
3. 报告效应量（Cohen's d 或 Cliff's delta）与 95% CI。
4. 多重比较用 BH-FDR 校正，q<0.05 视为显著。

## 3. 方法段落（可直接引用）
> 本研究对关键结论进行统计检验。首先使用 Shapiro-Wilk 检验评估正态性，不满足正态性假设时采用 Mann-Whitney U 检验。效应量以 Cohen's d 或 Cliff's delta 报告，并给出 95% 置信区间。多重比较采用 Benjamini-Hochberg FDR 校正，校正后 q<0.05 视为显著。所有检验均为双侧，显著性水平 α=0.05。

## 4. 注意事项
- 样本量小于 30 时慎用参数检验。
- 配对设计需用配对检验。
- 所有 p 值保留 3 位小数。
