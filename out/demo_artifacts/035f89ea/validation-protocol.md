# 验证协议说明与评估脚本

> 说明：本协议为方案级模板。所有性能数字为「示意值，需真实数据验证」。

## 1. 数据结构判定

| 结构 | 判据 | 折法 |
|---|---|---|
| 独立同分布 | 样本间无分组、无时序 | K 折交叉验证 |
| 分组 | 存在 group_id 且组内相关 | GroupKFold |
| 时序 | 存在时间戳且需防泄漏 | TimeSeriesSplit |

当前判定：待真实数据确认。

## 2. 折法与参数

- K 折：K=5，重复 5 次不同随机种子，报告均值±标准差。
- 分组：GroupKFold(n_splits=5)，分组字段 group_id。
- 时序：TimeSeriesSplit(n_splits=5)，按时间升序。
- 随机种子集合：{42, 2024, 7, 123, 999}。

## 3. 嵌套交叉验证

- 外层：评估泛化性能。
- 内层：调参，网格搜索或随机搜索。
- 调参空间示例：
  - 逻辑回归：C ∈ {0.01, 0.1, 1, 10}。
  - 梯度提升树：n_estimators ∈ {100, 300, 500}，max_depth ∈ {3, 5, 7}，learning_rate ∈ {0.01, 0.05, 0.1}。

## 4. 外部验证集

- 若样本量 ≥ 5000，保留 20% 作为独立外部验证集，不参与调参与折内评估。
- 若样本量 < 5000，仅用交叉验证，并在报告中声明无外部验证。

## 5. 评估指标

| 任务 | 主指标 | 辅指标 |
|---|---|---|
| 回归 | RMSE | MAE, R² |
| 二分类 | AUC-ROC | AUC-PR, F1, Brier |
| 多分类 | Macro-F1 | 混淆矩阵 |

## 6. 防泄漏检查清单

1. 填补、编码、标准化必须放在 Pipeline 内，仅在训练折拟合。
2. 目标编码必须使用折内统计，禁止全量统计。
3. 时序任务禁止未来信息进入训练。
4. 分组任务禁止同组样本跨折。
5. 缺失指示变量在划分前生成，不引入目标信息。

## 7. 可复现声明

- 固定随机种子、固定划分、记录库版本。
- 所有结果需附运行环境与数据版本哈希。
- 本协议中性能数字均为示意值，需真实数据验证。
