# 研究范围与公理化基础说明

## 1. 研究目标
验证统计估计量 \(\hat{\theta}_n\) 在样本量有限、假设被违反时的稳健性。核心命题：在满足矩条件、独立同分布（i.i.d.）与有限方差的前提下，\(\hat{\theta}_n\) 依概率收敛于真值 \(\theta\)，且 \(\sqrt{n}(\hat{\theta}_n - \theta)\) 依分布收敛于 \(N(0, \sigma^2)\)。

## 2. 概率空间与可测性
- 概率空间 \((\Omega, \mathcal{F}, P)\)，\(\mathcal{F}\) 为 \(\sigma\)-代数，满足封闭性：可数并、可数交、补集封闭。
- 随机变量 \(X_i: \Omega \to \mathbb{R}\) 为 \(\mathcal{F}\)-可测。
- 样本 \(X_1, \dots, X_n\) 为独立同分布，\(E[X_i] = \mu\)，\(\text{Var}(X_i) = \sigma^2 < \infty\)。

## 3. 依赖公理与已证定理
- 公理：Zermelo-Fraenkel 集合论 + 选择公理（用于构造非可测集反例）。
- 已证定理：大数定律（Khinchin）、中心极限定理（Lindeberg-Lévy）、控制收敛定理、单调收敛定理、Fubini 定理、Markov 不等式、Chebyshev 不等式、Jensen 不等式、Hölder 不等式。

## 4. 前提闭合性核验
| 前提 | 状态 | 备注 |
|------|------|------|
| 矩条件 \(E|X|^2 < \infty\) | 闭合 | 保证方差有限 |
| 独立性 | 闭合 | i.i.d. 假设 |
| 同分布 | 闭合 | 同上 |
| 可测性 | 闭合 | \(X_i\) 为 Borel 可测 |

## 5. 依赖关系图
\((\Omega, \mathcal{F}, P)\) → 可测性 → 独立性 → 矩条件 → 大数定律 → 中心极限定理 → 渐近正态性。

## 6. 适用范围与边界
- 适用于 \(n \to \infty\) 的渐近框架。
- 有限样本下需借助 Edgeworth 展开或 Bootstrap 校正。
- 违反独立性（如强相关）或矩条件（如 Cauchy 分布）时命题失效。

**注：本说明为方案级产出，具体数值需真实数据验证。**
