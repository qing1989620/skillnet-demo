# EDA 报告与剂量-响应数据质量评估

## 1. 数据概览
- 输入文件：raw_dose_response.csv（示意）
- 记录数：120 条（示意值，需真实数据验证）
- 剂量范围：0.01–1000 μM，转换为 log10(μM) 后为 -2 至 3
- 抑制率范围：0.02–0.95（示意值，需真实数据验证）
- 缺失值：3 条（标记不删除）
- 异常点：2 条（标记不删除）

## 3. 平台期覆盖判断
- 最低剂量抑制率均值：0.03（接近 0，Bottom 可识别）
- 最高剂量抑制率均值：0.95（接近 1，Top 可识别）
- 结论：Bottom 和 Top 均可从数据中估计，无需强制固定。若最低剂量抑制率 > 0.1 或最高剂量 < 0.9，则建议固定 Bottom=0 或 Top=1。

## 4. 低置信剂量点
- 所有剂量组 n=3，满足 n≥3 要求。
- 若某剂量组 n<3，标记为低置信，不参与最终 IC50 拟合或仅作敏感性分析。

## 5. 异常点与缺失值
- 异常点定义：|抑制率 - 组中位数| > 3×MAD。
- 缺失值：保留在数据集中，拟合时自动排除。
- 审计日志：clean-data-with-audit-log.csv 中记录每条标记原因。

## 6. 初步结论
- 数据覆盖 0–100% 抑制范围，适合 4PL 拟合。
- 所有数值均为示意值，需真实数据验证。
