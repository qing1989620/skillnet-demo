研究思路

以剂量-响应数据为输入，先做清洗与结构探查（统一剂量为 log10(μM)、抑制率为 0-1 小数，异常点标记不删除），再做 EDA 判断平台期覆盖与 Top/Bottom 可识别性，随后用 4PL/3PL 非线性最小二乘拟合 IC50 并用 bootstrap 量化不确定性，最后通过残差诊断与稳健性审计验证结论，交付矢量剂量-响应图与可复现报告。

执行步骤（5 步）

S1读取原始剂量-响应表，统一剂量单位为 log10(μM)、抑制率为 0-1 小数，检查主键（dose×replicate×group）唯一性，标记缺失与异常点（不删除），输出带审计日志的干净数据表与数据字典。
调用技能 data-cleaning
关键参数
  • 剂量单位统一为 log10(μM)，理由：跨数量级剂量直接拟合会产生数值偏差且参数不可解释
  • 抑制率统一为 0-1 小数，理由：避免 0-100% 与 0-1 混用导致 Top/Bottom 解释错误
  • 异常点判定用业务规则（如超出载体对照均值±3SD 或明显违反单调性），理由：纯统计阈值会误删真实生物学变异
  • 缺失行保留并标记，理由：直接删除会造成选择偏差
预期产出
干净数据表（dose、response、replicate、group）、清洗审计日志、数据字典
校验：清洗后主键唯一；审计日志可逐步复现；关键字段分布前后变化有解释；剂量-响应散点无系统性单位错位
S2按剂量分组计算均值、SD、n，绘制剂量-响应散点与分布图，检查最低剂量抑制率是否接近 0、最高剂量是否接近 100%，判断 Bottom/Top 是否需固定，标记 n<3 的低置信剂量点。
调用技能 eda-profiling
关键参数
  • 分组统计 n、mean、SD，理由：为后续拟合权重与置信度判断提供依据
  • 平台期判据：最低剂量抑制率≤5% 且最高剂量≥95% 视为覆盖平台期，否则固定 Bottom=0 或 Top=100 改用 3PL
  • n<3 的剂量点标记为低置信，理由：重复不足时该点均值不稳定
  • log10(dose) 与 dose 不同时进入模型，理由：避免共线性
预期产出
EDA 报告、剂量-响应散点图、平台期覆盖判断与模型形式选择建议
校验：分布图覆盖全部剂量点；组间样本量差异已标注；曲线形态支持所选模型形式（4PL 或 3PL）
S3用非线性最小二乘拟合 4PL：y = Bottom + (Top-Bottom)/(1+10^((logIC50-x)*HillSlope))；若 Bottom 固定为 0 或 Top 固定为 100 则用 3PL，并以 F 检验比较嵌套模型；对 IC50 做 bootstrap 估计 95% CI。
调用技能 dose-response-ic50-estimation
关键参数
  • 初始值 Bottom=min(y)、Top=max(y)、logIC50=median(log10(dose))、HillSlope=1，理由：贴近数据范围提高收敛概率
  • bootstrap 重复次数 ≥10000，重采样单位=独立实验批次/孔，随机种子固定并写入日志，理由：保证 CI 可复现且不过窄
  • 样本量梯度 n ∈ {10,100,1000,10000} 做收敛检查，理由：验证估计量渐近性质
  • 多命题比较用 Bonferroni α'=0.05/k，理由：控制假阳性
  • α=0.05 双侧，理由：常规显著性水平
预期产出
IC50 估计表（点估计、95% CI、HillSlope、Top/Bottom、R²、残差标准误）、bootstrap 不确定性与稳健性审计报告
校验：参数收敛且标准误有限；残差无系统趋势；bootstrap 收敛曲线斜率与理论 O(n^{-1/2}) 在置信带内一致；更换种子后结论方向不变
S4对 IC50 估计量做稳健性审计：核验前提（独立性、矩条件）、执行预注册蒙特卡洛、泄漏审计（种子记录、样本流分配）、构造边界反例（HillSlope→0、HillSlope 极大、Bottom/Top 不可识别）做敏感性分析。
调用技能 estimator-robustness-audit
关键参数
  • 预注册参数（n、重复次数、检验方法）运行前锁定，理由：防止事后调参
  • 每个命题独立随机流，禁止复用样本，理由：避免伪验证
  • 分布形状参数 ±10%、±25% 扰动，理由：检验结论对分布假设的敏感性
  • HillSlope 敏感性分析，理由：HillSlope 接近 0 或极大时 IC50 置信区间会爆炸
预期产出
公理化前提核验表、蒙特卡洛验证报告、泄漏审计报告、反例清单与适用范围表
校验：每个命题前提可追溯到已声明假设；更换种子重跑结论方向不变；样本流与命题一一对应无重叠；反例确实满足前提但违反结论
S5绘制出版级剂量-响应图：x 轴 log10(dose)，y 轴抑制率 0-1 或 0-100%，散点+拟合曲线+95% 置信带，误差条为 SD 或 SEM，标注 IC50 与置信区间、HillSlope、样本量 n，导出 PDF/SVG 矢量格式。
调用技能 scientific-visualization
关键参数
  • 字体 ≥7 pt，理由：缩放到单栏宽度仍可读
  • 配色用 Okabe-Ito 等色觉障碍友好方案，理由：满足可访问性要求
  • 误差条为 SD 或 SEM 并标注样本量，理由：显式呈现不确定性
  • 导出 PDF/SVG 矢量格式，理由：出版级要求
预期产出
矢量剂量-响应图（PDF/SVG）、绘图脚本、图注文本
校验：坐标轴与单位标注完整；误差条与样本量齐备；图为矢量且字号达标；IC50 标注与统计结果一致

风险与应对

  • 剂量-响应曲线未覆盖平台期导致 Top/Bottom 不可识别、IC50 外推不可靠：检查最低/最高剂量抑制率，必要时固定 Bottom=0 或 Top=100 改用 3PL 并在报告中说明
  • HillSlope 接近 0 或极大时 IC50 置信区间爆炸：报告 profile likelihood CI 而非仅 Wald CI，并做 HillSlope 敏感性分析
  • bootstrap 重采样单位错误（按孔而非按独立实验批次）导致 CI 过窄：明确重采样单位并记录在审计日志，用分层 bootstrap 验证
  • 数据清洗阶段静默删除异常点导致选择偏差：异常点标记而非删除，保留审计日志，做含/不含异常点的敏感性对比
