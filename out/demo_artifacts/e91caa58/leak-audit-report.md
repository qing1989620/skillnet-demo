# 泄漏审计报告与适用范围表

## 1. 审计目标
确保 IC50 估计过程中无数据泄漏、无信息重复使用、随机种子可复现。

## 2. 审计条目
| 检查项 | 要求 | 结果 |
|--------|------|------|
| 随机种子记录 | 所有随机过程记录种子 | 通过（种子=42） |
| 样本流分配 | 训练/验证/测试不重叠 | 通过 |
| 预处理泄漏 | 标准化/归一化仅用训练集 | 通过 |
| 特征选择泄漏 | 无基于全数据的特征选择 | 通过 |
| 重复测量处理 | 同一 replicate 不跨集 | 通过 |

## 3. 适用范围表
| 条件 | 适用范围 | 边界 |
|------|----------|------|
| 剂量范围 | 覆盖 0–100% 抑制 | 若未覆盖，IC50 外推不可靠 |
| 重复数 | n≥3 | n<3 标记低置信 |
| 模型 | 4PL/3PL | HillSlope 极端时退化 |
| 数据分布 | 独立同分布 | 若存在批次效应，需混合模型 |

## 4. 结论
- 泄漏审计通过，所有数值为示意值，需真实数据验证。
- 本方案适用于标准剂量-响应实验，不适用于非单调或双相响应。
