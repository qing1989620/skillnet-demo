## 3. 平台期覆盖判断

- **Bottom 可识别性**：最低剂量抑制率均值 = 0.98（示意值），未接近 0，Bottom 不可识别，建议固定 Bottom=0 或改用 3PL。
- **Top 可识别性**：最高剂量抑制率均值 = 0.05（示意值），未接近 1，Top 不可识别，建议固定 Top=1 或改用 3PL。
- **结论**：当前数据平台期覆盖不足，4PL 中 Top/Bottom 可能不可识别，需固定或改用 3PL。

## 4. 剂量-响应散点图

- x 轴：log10(dose)，范围 -3 至 2

- 散点：每个剂量组均值 ± SD
- 拟合曲线：4PL 或 3PL

## 5. 数据质量判据（可直接套用）

1. 最低剂量抑制率均值 > 0.9 且最高剂量抑制率均值 < 0.1 → 平台期覆盖不足，Top/Bottom 不可识别。
2. 若某剂量组 n < 3 → 标记低置信，拟合时可选剔除。
3. 若某剂量组 SD > 0.2 → 检查重复孔一致性，必要时标记异常。
4. 若 log10(dose) 与 dose 同时出现在模型中 → 违反模型假设，需二选一。

## 6. 使用边界

- 本 EDA 仅适用于细胞存活率数据，不适用于其他终点。
- 若平台期覆盖不足，IC50 外推风险高，需在报告中显式说明。
- 所有结论需在真实数据上重新验证。
