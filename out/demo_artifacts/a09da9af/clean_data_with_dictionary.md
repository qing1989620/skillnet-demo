# 干净数据集与数据字典

> **诚实声明**：本文件中的示例数据均为**示意值，需真实数据验证**。实际数据清洗结果以运行脚本后的输出为准。

## 1. 数据集概述

- **文件名称**：`clean_dose_response.csv`
- **记录数**：示例 30 行（示意值，需真实数据验证）
- **字段数**：6
- **剂量单位**：统一为 μM（若原始为 nM 或 mg/mL，已按分子量换算并记录于审计日志）
- **响应单位**：抑制率，0–1 小数（若原始为百分比，已除以 100）
- **缺失值处理**：缺失 `response` 的行保留但标记 `qc_flag=missing`，不参与拟合
- **异常点处理**：标记 `qc_flag=outlier`，不删除，拟合时可选剔除

## 2. 数据字典

| 字段名 | 类型 | 单位 | 允许范围 | 缺失规则 | 说明 |
|---|---|---|---|---|---|
| `dose` | float | μM | >0 | 不允许 | 化合物浓度，已统一单位 |
| `log10_dose` | float | log10(μM) | 实数 | 由 dose 计算 | 拟合用自变量，与 dose 不共存于同一模型 |
| `response` | float | 抑制率(0–1) | [0,1] | 允许，标记 missing | 细胞存活抑制率，1 表示完全抑制 |
| `replicate` | int | — | ≥1 | 不允许 | 同一剂量下的重复孔编号 |
| `group` | string | — | 非空 | 不允许 | 实验分组，如 `control`、`treated` |
| `qc_flag` | string | — | `ok`/`outlier`/`missing`/`low_n` | 不允许 | 质量标记，异常点不删除 |

## 3. 清洗规则（可直接套用）

1. **单位统一**：若原始剂量单位为 nM，则 `dose_μM = dose_nM / 1000`；若为 mg/mL，需提供分子量 MW，`dose_μM = (dose_mg/mL / MW) * 1e6`。
2. **响应统一**：若原始为 0–100%，则 `response = percent / 100`。
3. **重复孔检查**：同一 `dose` 下 `replicate` 应唯一；若重复，保留首次出现并标记 `qc_flag=duplicate`。
4. **缺失值**：`dose` 缺失则整行剔除并记录；`response` 缺失则保留行并标记 `qc_flag=missing`。
5. **异常点判定**：采用 MAD 法，对同一剂量组内 `response` 计算中位数与 MAD，若 `|response - median| > 3 * 1.4826 * MAD` 则标记 `qc_flag=outlier`。
6. **低置信剂量点**：若某剂量组 `n < 3`，标记 `qc_flag=low_n`，拟合时可选剔除。
7. **审计轨迹**：所有清洗操作写入 `cleaning_audit_log.csv`，包含时间戳、操作、影响行数、原因。

## 5. 使用边界

- 本数据集仅适用于 4PL/3PL 拟合，不适用于时间依赖性毒性模型。
- 若最高剂量抑制率未接近 100%，Top 不可识别，需固定或改用 3PL。
- 若最低剂量抑制率未接近 0%，Bottom 不可识别，需固定或改用 3PL。
- 所有结论需在真实数据上重新验证。
