## 研究思路

以剂量-响应数据为输入，先做清洗与单位统一并保留审计轨迹，再做 EDA 判断平台期覆盖与 Top/Bottom 可识别性，随后用 4PL/3PL 非线性最小二乘拟合 IC50 并做 bootstrap 与残差诊断，最后用稳健性审计验证估计量在有限样本与假设违反下的表现，并输出出版级矢量图与可复现报告。

## 执行步骤

### S1 · 读取原始剂量-响应数据，统一剂量单位为 μM 或 log10(μM)、抑制率为 0-1 小数；检查重复孔、缺失值与异常点，异常点标记而非删除，输出带审计日志的干净数据表（dose、response、replicate、group）。

- **调用技能**：`data-cleaning`
- **关键参数**：剂量单位统一为 μM 或 log10(μM)，避免跨数量级拟合偏差
- **关键参数**：抑制率统一为 0-1 小数，避免 Top/Bottom 解释错误
- **关键参数**：异常点判定用业务规则（如超出载体对照 3SD 或负值），不用纯统计阈值
- **关键参数**：缺失率阈值 >20% 的剂量点标记为低置信并保留
- **预期产出**：干净数据集、清洗审计日志、数据字典
- **校验判据**：清洗后主键唯一；审计日志可复现每一步；关键字段分布变化有解释；剂量-响应散点无系统性单位错位

### S2 · 按剂量分组计算均值、SD、n，检查最低剂量抑制率是否接近 0、最高剂量是否接近 100%，判断 Bottom/Top 是否需固定；标记 n<3 的低置信剂量点；确认 log10(dose) 与 dose 不共存于同一模型。

- **调用技能**：`eda-profiling`
- **关键参数**：最低剂量抑制率接近 0（如 <10%）则 Bottom 可固定为 0
- **关键参数**：最高剂量抑制率接近 100%（如 >90%）则 Top 可固定为 100
- **关键参数**：n<3 的剂量点标记为低置信
- **关键参数**：log10(dose) 与 dose 不共存，避免共线性
- **预期产出**：EDA 报告、剂量-响应散点图、候选模型形式建议
- **校验判据**：分布图覆盖全部剂量点；组间样本量差异已标注；曲线形态支持所选模型形式

### S3 · 用非线性最小二乘拟合 4PL：y = Bottom + (Top-Bottom)/(1+10^((logIC50-x)*HillSlope))；初始值 Bottom=min(y)、Top=max(y)、logIC50=median(log10(dose))、HillSlope=1；若 Bottom 固定为 0 或 Top 固定为 100 则用 3PL 并以 F 检验比较嵌套模型；对 IC50 做 bootstrap 并做残差诊断。

- **调用技能**：`dose-response-ic50-estimation`
- **关键参数**：α=0.05，嵌套模型比较用 F 检验
- **关键参数**：bootstrap 重复次数 ≥10000，重采样单位=独立实验批次/孔，随机种子固定并写入日志
- **关键参数**：样本量梯度 n ∈ {10,100,1000,10000} 做收敛检查
- **关键参数**：多命题比较用 Bonferroni α'=0.05/k
- **关键参数**：HillSlope→0 或极大时报告 profile likelihood CI 而非仅 Wald CI
- **预期产出**：IC50 估计表（点估计、95% CI、HillSlope、Top/Bottom、R²、残差标准误）、bootstrap 不确定性与稳健性审计报告
- **校验判据**：参数收敛且标准误有限；残差无系统趋势；嵌套模型比较 p 值经校正后报告；bootstrap 收敛曲线斜率与理论 O(n^{-1/2}) 在置信带内一致；更换种子后结论方向不变

### S4 · 对 IC50 估计量做公理化前提核验、预注册蒙特卡洛验证、泄漏审计与反例边界审计；用 Cauchy、AR(1) 强相关、重尾 Pareto 等构造使命题失效的极端情形，对分布形状参数做 ±10%、±25% 扰动。

- **调用技能**：`estimator-robustness-audit`
- **关键参数**：重复次数 ≥10000，样本量梯度 n ∈ {10,100,1000,10000}
- **关键参数**：α=0.05 双侧，多命题 Bonferroni α'=0.05/k
- **关键参数**：n<5000 用 Shapiro-Wilk，n≥5000 用 Kolmogorov-Smirnov
- **关键参数**：每个命题独立随机流，禁止复用样本；种子运行前锁定
- **预期产出**：公理化前提表、严格证明文本、预注册蒙特卡洛报告、泄漏审计报告、反例清单与适用范围表
- **校验判据**：每个命题前提可追溯到已声明公理或已证定理；更换种子重跑后结论方向不变；样本流与命题一一对应无重叠；每个反例确实满足命题前提但违反结论

### S5 · 绘制出版级剂量-响应图：x 轴 log10(dose)，y 轴抑制率 0-1 或 0-100%，散点+拟合曲线+95% 置信带，误差条为 SD 或 SEM，标注 IC50 与置信区间、HillSlope、样本量 n；导出 PDF/SVG 矢量格式。

- **调用技能**：`scientific-visualization`
- **关键参数**：字体 ≥7 pt，配色用 Okabe-Ito 等色觉障碍友好方案
- **关键参数**：误差条为 SD 或 SEM，需显式标注
- **关键参数**：导出 PDF/SVG 矢量格式
- **关键参数**：坐标轴与单位标注完整
- **预期产出**：出版级剂量-响应曲线矢量图（PDF/SVG）与绘图脚本、图注文本
- **校验判据**：坐标轴与单位标注完整；误差条与样本量齐备；图为矢量且字号达标；IC50 标注与统计结果一致

## 风险与应对

- 剂量-响应曲线未覆盖平台期导致 Top/Bottom 不可识别，IC50 外推不可靠——应检查最低/最高剂量抑制率，必要时固定 Bottom=0 或 Top=100 并报告为 3PL
- HillSlope 接近 0 或极大时 IC50 置信区间爆炸——应报告 profile likelihood CI 而非仅 Wald CI，并做 HillSlope 敏感性分析
- bootstrap 重采样单位错误（按孔而非按独立实验批次）导致 CI 过窄——应明确重采样单位并记录在审计日志，用分层 bootstrap 验证
- 数据清洗阶段静默删除异常点导致选择偏差——应保留审计日志，异常点标记而非删除，做含/不含异常点的敏感性对比
