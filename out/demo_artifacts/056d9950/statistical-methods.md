# 统计方法说明

## 1. 设计类型与分组
- 本研究比较 `control` 与 `treatment` 两组。若同一受试者接受两种条件，则按配对设计处理；若两组为独立样本，则按独立设计处理。
- 主分析指标：`metric_a`、`metric_b`。显著性水平：α=0.05，双尾。

## 2. 前提检验
- 正态性：对每组分别使用 Shapiro-Wilk 检验；若 p<0.05 或偏度绝对值>1、峰度绝对值>3，则判定偏离正态。
- 方差齐性：独立设计使用 Levene 检验（中心化中位数）；若 p<0.05，则采用 Welch 校正。
- 配对设计：对差值做正态性检验；不满足时使用 Wilcoxon 符号秩检验。

## 3. 检验选择
- 独立且正态、方差齐：Student t 检验；方差不齐：Welch t 检验。
- 独立且非正态：Mann-Whitney U 检验。
- 配对且差值正态：配对 t 检验；否则 Wilcoxon 符号秩检验。

## 4. 效应量与置信区间
- 独立设计：报告 Cohen's d 或 Hedges' g；95% CI 采用非中心 t 分布或 bootstrap（B=10000，随机种子固定）。
- 配对设计：报告 Cohen's dz；95% CI 采用配对 bootstrap。
- 非参数检验：报告 rank-biserial r 或 Cliff's delta，并给出 bootstrap 95% CI。

## 5. 多重比较
- 若同一数据集涉及多个指标或多组比较，使用 Benjamini-Hochberg FDR 校正；同时报告 Bonferroni 作为保守对照。
- 报告校正前 p 值、校正后 p 值，并标注校正后是否仍显著。

## 6. 稳健性复核
- 参数与非参数两条路径交叉验证；检查效应量方向与均值差方向是否一致。
- 使用固定随机种子复现 bootstrap CI；核对自由度、样本量与缺失处理。
- 所有数值均为示意值，需真实数据验证。
