【这是什么】
  Agent 技能运维层演示：技能的发现 → 选择 → 关系编排 → 真实执行
  → 失败自动修复 → 程序化验收 → 产物 → 反馈 → 进化，全链路可追溯。

【30 秒跑起来】
  Windows : 双击 start.bat（自动装依赖 + 启动 + 打开浏览器）
  macOS/Linux : 终端执行 ./start.sh
  手动方式 : pip install -r requirements.txt && python run.py
  地址 : http://127.0.0.1:8848

【不需要配置就能用的功能】
  · 首页产品叙事 + 真实数据技能星图（98 技能 / 200 关系边，可拖拽悬停）
  · 三档检索对照（BM25 / Hybrid / Fabric 图扩展）
  · 技能库浏览 / 实验结果面板 / 跨框架导出（Claude Code·Cursor·Gemini·AGENTS）
  · 运行中心历史记录

【填密钥后解锁的功能】
  · 真实任务执行（沙箱跑 Python + 失败自动修复）
  · 技能驱动的方案生成 / 盲评 / 技能蒸馏进化 / 全链路闭环演示
  配置方法：把 .env.example 复制为 .env，填入 DEEPSEEK_API_KEY
  （https://platform.deepseek.com 注册获取；入口在页面顶栏有状态提示）

【第一次看什么（5 分钟路线）】
  1. 首页 Hero 星图：拖一拖、悬停看技能详情（30 秒）
  2. 首页中部输入任务 → 点「实时运行」→ 看星图点亮→收束成 DAG→执行（2 分钟）
  3. 点「技能星图」进深色沉浸模式，红圈是系统自己进化出的技能（1 分钟）
  4. 「完整面板」看评估实验数据与技能健康（1 分钟）
  5. docs/SkillNet-S1-交付报告.pdf —— 全部结论与数据的书面版

【目录说明】
  start.bat / start.sh   一键启动脚本
  requirements.txt       Python 依赖（5 个包，无重依赖）
  run.py / server.py     启动入口 / FastAPI 服务
  skillnet/              核心库（检索·编排·执行·验收·进化）
  web/                   前端页面（briefing/run/graph/dashboard）
  seed/ data/            技能种子数据 / 演化后的库快照
  tasks/                 评测任务集（dev / heldout）
  tests/                 自动化测试（pytest -q，约 3 秒，不联网）
  tools/                 基准与自检脚本
  docs/                  交付报告 / 技术说明 / 迭代日志
  out/bench/             实验原始数据（JSON，含 manifest 溯源）
  out/final_shots/       关键页面截图
  .env.example           配置模板（复制为 .env 使用）

【常见问题】
  · 端口被占用：python run.py --port 9000
  · 页面显示"模型密钥未配置"：真实执行类按钮会给出中文说明，
    浏览/检索/星图/导出不受影响
  · 依赖安装慢：pip install -r requirements.txt -i
    https://pypi.tuna.tsinghua.edu.cn/simple
  · 运行记录在哪：out/runs/（每条 Run 独立文件，含事件流与产物）
  · 如何重新验证测试：python -m pytest tests/ -q（预期 35 passed）
