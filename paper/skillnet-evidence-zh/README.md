# 中文论文与可复核数据，2026-11-11

论文题目：**开放技能包的证据核验与条件化效用：来自 SkillNet 的受控实验研究**。
这是有实际实验结果的研究稿，尚未投稿，不代表已取得期刊接收、独立人审认证或网络优化优势。

## 本轮实际推进

在此前 200 个原始包、381 个接口案例、54 次真实模型评价、1,152 条历史选择回放的基础上，
新增 **300 次真实 DeepSeek 请求**：30 个输入 × 五臂 × 两次重复。
24 个范围内 CSV 输入来自 12 个构造条件，每种条件各有 8/48 行；另有六个明确元数据边界输入。
五臂固定为无 Skill、原始包、原包加操作契约、无关上下文、仅操作契约。
这是受限文本执行器产生 JSON 产物的实验；没有执行社区脚本或模型生成代码。

| 观察结果 | 数据 | 允许的解释 |
|---|---:|---|
| 完整范围内产物 | 23/240，9.58% | 这个固定设计中的实际合格率 |
| 逐项检查平均通过 | 89.21% | 事后测量诊断，不是原项目质量分 |
| 48 行输入 | 0/120 完整合格 | 该规模的本次结果，不能认证绝对能力上限 |
| 明确元数据边界 | 60/60 合格 | 不代表实际二进制解码或操作系统安全 |
| 原包加契约相对原包 | +4.17 个百分点，条件区间跨零 | 未建立稳定收益 |
| 用量与费用 | 输入 1,394,720、输出 32,153 token；峰价上界 ¥3.046664 / $0.4569996 | 两种独立定价口径，不是汇率换算或提供商账单 |

研究测试合计 198 项通过，其中本轮新增九项。24 个 CSV 真值由生成器、标准库读取和 pandas
三路核对，390 项验收器诊断通过。三路共享任务语义，独立人类质量标签仍为零。
温度零下仍有七对重复的完整成功状态不同。论文完整保留失败和未知，没有补造正向优势。

## 官方双栏模板与本地编译

采用 **Elsevier CAS `cas-dc` 2.4（2024-05-04）**，不是自行模仿排版。
官方来源：[Elsevier LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions)、
[CTAN CAS bundle](https://ctan.org/tex-archive/macros/latex/contrib/els-cas-templates?lang=en)。
类文件保持用户 TeX Live 安装中的原版；中文、页脚、无 ORCID 时的处理及字体兼容在 `main.tex` 内配置。
模板代表版式，不能证明论文质量或目标期刊匹配。

在此目录运行：

```powershell
.\build.ps1
```

默认使用用户指定的编译器目录：
`D:/zhuomian_app/latex/texlive/2026/bin/windows`。
脚本运行 XeLaTeX、BibTeX、两轮交叉引用编译，禁用 shell escape；不会调用任何模型 API。
输出 `SkillNet_中文研究论文.pdf`。其他安装可传入：

```powershell
.\build.ps1 -TexBin 'C:/texlive/2026/bin/windows'
```

需要 TeX Live 的 CAS、ctex/Fandol、STIX、TikZ、natbib 等已安装组件。
摘要正文直接写在 `main.tex` 中，以兼容 CAS 的 verbatim 摘要捕获。
`sections/` 为正文，`references.bib` 为 44 篇文献；CAS `.cls/.sty/.bst` 由本地 TeX Live 提供。

## 不付费即可重算

在有 numpy/pandas 的 Python 3.11/3.12 环境运行：

```powershell
python reproduce.py
```

该脚本从随稿输入和逐次产物重新验收 300 条结果，重算五个条件簇配对区间、
重复差异和费用上界，检查用量、分母及构造答案一致性；不读密钥、不联网、不补做调用。
依赖列在 `requirements-reproduce.txt`，实际本机版本在 `results/environment.json`。
安装 matplotlib 后可运行 `python figures/plot_results.py` 重画三种真实数据图表。
Windows 使用微软雅黑，其他系统需要 Noto Sans CJK SC。
`python build_assets.py` 可由随稿数据重建六张数据表、宏、CSV 与参考文献。

`code/` 保留首个请求前冻结的实验/验收/分析源码、当时的 API 客户端及包读取器。
这六个执行文件的原始字节由 `results/executed-code-manifest.json` 绑定；
`diagnostics.py` 是另外标识的事后分析，`manifest.py` 为离线复核提供原项目哈希工具。
在完整仓库中运行付费实验还依赖原始来源快照、研究包和本地配置；本数据包不分发完整第三方技能文本。
不可变原始响应、账户快照、请求材料与预算日志保留在本地运行目录，而非公开压缩包。
因此离线重算可复核公开产物和统计，不能代替提供商的独立审计或证明每个响应的外部签名。

## 数据目录与研究边界

`results/constructed-tasks.jsonl` 含构造输入和预期答案；答案未进入被测模型请求。
`trial-outcomes.jsonl` 含 300 份真实生成产物、失败字段、返回用量、响应指纹；
`trial-outcomes.csv` 供快速查看。`analysis.json` 是预定分析，
`posthoc-diagnostics.json` 是事后测量解释，`run-plan.json` 保留请求前约束。
其他 summary 文件是前期实验聚合结果，完整原始实现和元数据在原仓库研究分支。

本轮只有一个目标技能、一个可变模型别名、两个输入规模和目的性构造条件，
每输入两次重复不等于两个独立任务。尚缺跨来源真实工具实验、独立双盲语义标签和校准留出。
论文没有将引用定位率当作质量准确率，没有把检索集合覆盖当作实际编排成功，
也没有将确定性验收门禁回放包装成模型求解能力提升。

下一阶段优先增加确定性工具强对照与隔离工具执行，用新输入继续验证单技能条件效用；
再结合独立人审检验证据语义，最后研究证据引导的技能网络选择及验证预算分配。
每一步继续以完整产物、错误放行、覆盖、费用和旧任务回归决定是否确实改进。
