# Skill 条件效用与独立产物实验，2026-11-11

中文论文和可重算数据位于 `paper/skillnet-evidence-zh/`。
本包在既有质量核验研究上增加真实任务产物对照，使用官方 DeepSeek API，
没有执行第三方技能代码。它不是已经完成的通用技能认证或生产网络优化。

首次请求前冻结 30 个输入、五个臂、两次重复、五个配对比较、预算与源码。
固定 D1 技能 `data-quality-auditor` 的主文档与 profiler 文本作为原始上下文；
比较无 Skill、原包、原包加操作契约、无关上下文和仅操作契约。
24 个 CSV 输入来自 12 条件 × 8/48 行，另六个是明确元数据边界。

300 次请求全部完成，无重试、截断、未运行或基础设施失败。
范围内完整合格分别为 4、2、4、6、7/48；合计 23/240。
48 行 0/120，明确边界 60/60。不能据此判定任一方法跨技能最优，
或认定边界用例测试了真实文件解码/系统权限。
原包加契约相对原包 +4.17 个百分点，12 个构造条件簇的区间跨零，未建立稳定优势。
事后平均逐项检查通过 89.21%，完整成功仅 9.58%；这不是原项目质量分的相关性实验。

实际输入 1,394,720、输出 32,153 token。按已核对峰价的保守上界为
¥3.046664 / $0.4569996，非独立账单。用户已在会话中明确授权持续使用 DeepSeek；
密钥只在本机被忽略的配置中，研究源码与论文不包含密钥。

不可覆盖的运行目录：

- `out/research/skill-execution/20261111-prepared-v1`：未用于模型的初版准备。
- `out/research/skill-execution/20261111-prepared-v2`：模型结果前固定的最终材料。
- `out/research/skill-execution/20261111-five-arm-v1`：300 次真实响应、用量、预算及源码快照。
- `out/research/skill-execution/20261111-analysis-v1`：预定比较和另列的事后诊断。

模块用途：`tasks.py` 生成输入/真值及独立 CSV/pandas 读取核对，
`experiment.py` 实施固定对照和费用并发守卫，`analysis.py` 重验产物与条件配对分析，
`diagnostics.py` 是结果产生后的解释性测量诊断，不并入预定效果终点。
所有代码都通过版本指纹与原始运行记录连接；旧研究包保持原字节。
