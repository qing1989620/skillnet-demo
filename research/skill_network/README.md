# 证据条件化的 SkillNet 路径优化：可执行实验

这是第二项方法的实际实现。它将开发集的节点产物核验证据、代码版本、输入条件与 AND 前提约束结合，选择预算内可以完成全部必要阶段的路径。使用现有 `skillnet.frontier.plan` 作为原生最短路径强对照。没有训练神经网络，也没有重新发明最短路径算法。

## 方法与判定

输入为任务意图、解析/阈值条件、18 个自建算子的公开元数据、开发集证据以及上下文字节预算。选择器看不到测试答案、实际输出、实现标签。证据必须匹配完整工作资源的 SHA-256；相同 ID 换代码不能沿用旧版本的通过证据。

对匹配条件下的 s 次成功、n 次探测，使用 `(s+1)/(n+2)` 作为排序启发量。排除已经观察到条件内失败的节点，再枚举满足全部前提、最多 5 次调用且不超预算的完整路径；目标为各节点负对数启发量之和，加 `0.05*字节/预算+0.02*调用数`。这不是校准后的路径成功概率。未知节点仍可作为先验候选，故最终必须执行并由独立验收器核对完整行与精确指标。

## 冻结实验和实际发现

- 公开 UCI Iris/Wine 用于开发，WDBC/Banknote 用于留出；4 份原始文件及许可、DOI、SHA-256 随数据保存。
- 数据经明确的重复、跨分割、空字段、CSV 引号、阈值干预，形成开发 128 个、主留出 128 个、精度压力 24 个输入。它们是公开数据派生的构造任务，不是自然任务或原始分类准确率。
- 928 次实际开发探测；主运行 7,856 个选择决定，共享 1,204 次相同输入与路径的实际执行。共享执行、3 档预算、ID 置换和容器复现均不增加独立任务数。
- 主留出成功数（1.0/1.5/2.0 倍原生最短路径字节预算）：完整方法 **16/128/128**，原生元数据最短路径 **16/16/16**，人工固定流程及全局证据风险路径均为 **0/128/128**。三档均值分别 70.83%、12.50%、66.67%。相对强对照的增量仅 4.17 个百分点，来自紧预算。
- 中预算相对人工流程少 32/448=7.14% 算子调用，平均上下文少 82/2018.5=4.06% 字节；加上 928 次取证，本批完整方法 10.5 次调用/正确产物，人工流程 3.5 次。因此本批全成本不优于已知正确人工流程。
- 换版本后，完整方法与全局风险路径仍为 128/128；仅 ID 绑定和人工流程均为 64/128。不能将这项收益全归因于条件化。
- 单独精度压力在中预算为 24/24；事后把精度与版本变化合并，完整方法只通过 **12/24**。记录了反例，未回调方法参数。
- 原自然 SkillNet 历史选择回放仍未证明普遍改进。本实验只证实 18 个自建算子网络的有限条件收益。

## 零付费复现

在仓库根目录执行（不读取模型密钥）：

```powershell
python -m pip install -r research/skill_network/requirements.txt
python -m research.skill_network.reproduce
python -m research.skill_network.reproduce --execute
python -m pytest research/skill_network/tests -q
```

第一条复现核对源文件指纹、任务重建、开发证据、7,856 个路径决定、全部输出判定、事后反例和统计分析，不执行程序；`--execute` 另在去凭据子进程重跑 2,264 条已有请求（928+1204+132），不是新独立输入。只运行本项目固定的自建 worker，不接受任意社区代码。本机子进程不被宣称为恶意代码沙箱。

Linux Docker 复现使用 `SKILL_NETWORK_IMAGE` 指向不可变官方镜像摘要，然后加 `--execute --backend docker`。容器无网络、只读挂载、非 root、去能力、128 MiB/1 CPU/32 PID。CI 在公开仓库使用标准免费 runner，不调用模型、不上传付费存储 artifact。

`results/*/manifest.json` 是字节完整性清单，不是统计预注册或第三方科学认证。方案和代码快照在测试执行前冻结，但研究者已设计和查看任务语义，不能声称独立盲测。完整的论文正文、各基线、全部负结果与可移植来源包见 v2 论文。
