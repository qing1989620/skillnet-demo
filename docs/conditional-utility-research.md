# 条件收益与失败边界：真实执行研究

2026-10-14 · 完整交付版 2026.10.14-complete.21 · 功能入口 `/utility`。

本轮完成两次先冻结、再训练和测试的研究，共 **80 道新封存任务、48 次真实模型调用、2,684 次固定程序执行**。条件模型没有提高本轮大模型的有效任务交付率；反例引导的边界修正在另一份新数据上减少了无效执行，没有误拒有效任务。正式技能路由和奖励没有因此更新。

## 研究判断

检索 Recall 提升不能证明任务质量提升。新的判断对象是：特定技能版本，在给定输入、目标和共存技能条件下，是否改变真实产物，以及在哪里失败。

例如，“删除空值”在要求保留观测行数时可能破坏结果，在要求只保留完整记录时可能有益。成功运行、满足要求、相对已有策略更好分别计量；提前拒绝无效任务也不能冒充有效任务的质量提升。

相关方向已有先例：[ASSAY](https://arxiv.org/abs/2606.15390) 用随机屏蔽测量贡献并按任务抑制负作用；[Contract2Tool](https://arxiv.org/abs/2606.07904) 学习前置条件与效果；[SkillHEX](https://arxiv.org/abs/2608.05628) 将可证伪失败假设转成可执行测试。本项目不把条件化、贡献估计或失败修复单独宣称为首创。产品价值在于把来源、契约、选择、真实文件、反例和十二门准入接成可复核的使用路径。

## 第一轮：条件收益预测

冻结协议：`36d9b398419127dcae22006c90173ff8816d6869dd0d63601d474073fb610f4b`。

160 道训练任务包括 128 道合成条件任务与 32 道合成失败任务。校准使用另外 68 道输入。封存测试有 32 道基于真实公开测量的任务与 8 道合成边界挑战。

真实测量来自 [Palmer Penguins](https://github.com/allisonhorst/palmerpenguins)，固定提交 `8957207b78d6ccd1b4654a9dd9c9041b657478ab`，CC0，整个来源未进入训练或校准。标识、集合划分、缺陷注入是实验变换，不能说成原科学数据本来存在这些问题。测试任务共享部分原始记录，不是 32 个独立来源。

去重、排除跨集合实体、删除空值三个登记程序构成 8 种完整组合，公共聚合程序相同。训练 1,280 次、校准 544 次、测试 640 次实际子进程执行；测试各重复两次。每臂写出原单元格保留的 CSV 与分组计数、有效数、和、均值 CSV。独立模块用不同的记录选择与 Decimal 算法复核全部字段；文件存在或模型说完成不构成合格标签。错误组合全部保留。

预测器为深度上限 8、最小叶样本 2 的多输出 CART，只读取执行前输入事实与任务契约，不读取任务 ID、来源 ID、测试结果或奖励。八个输出估计组合质量，另外八个估计执行失败。某技能的边际收益是在四种共存组合中，增加该技能前后质量差的平均值，仅适用于本登记程序、任务与干预分布，不能作为一般 LLM 技能永久分数，也不能简单相加。

模型摘要：`de80310337e6601834a919ea621b722904e1fa0d50f10737bf613512866cd389`。阈值仅按校准结果选择，取 1.0，之后整体保存封存预测，再运行测试。

| 策略 | 有效任务交付 | 无效任务提前拒绝 | 无效任务仍执行 |
|---|---:|---:|---:|
| 不调用清洗 | 13/32 | 0/8 | 8 |
| 全部调用 | 14/32 | 0/8 | 8 |
| 按明确契约选择 | 32/32 | 2/8 | 6 |
| 契约 + 基础条件检查 | 32/32 | 7/8 | 1 |
| 训练后的条件选择 | 32/32 | 7/8 | 1 |

原协议主对照为“全部调用”。为避免弱基线夸大收益，在训练启动后、封存测试预测和结果文件产生前另行冻结强规则分析计划，保存时间与代码指纹，没有改变原主协议或看结果后选规则。**候选胜过全部调用，但没有胜过简单契约规则。**

支持范围为 38/40 道任务，边际收益 MAE 0.13596，失败 Brier 诊断值 0.01316。它们不是校准证书。相对全部调用的 18 胜、0 负、14 平，也不能据同源任务的符号检验 p 值宣称跨领域可靠性。

真实边际作用同时出现正负：去重 8 正 / 8 负 / 24 零，跨集合排除 8 / 8 / 24，删除空值 10 / 8 / 22。没有给同一任务所有参与技能统一奖励。

## 真实大模型配对

预先选定封存测试中的 8 道有效任务和 4 道边界任务，每题两次配对，两种提示，共 **48 次实际 API 调用**。两组都看到完整任务、输入和观测；证据组额外看到冻结预测，不能看到该题执行结果。原始组没有被故意削弱。

请求别名 `deepseek-chat`、温度 0.2、输出预算 256 token、无隐式重试，配对顺序交替。实际返回模型字段为 **`deepseek-flash`**，没有不可变修订号，因此不能宣称锁定提供方权重快照。模型只选登记组合或拒绝，不能提交任意代码、命令或路径。

| 项目 | 原始提示 | 加入预测证据 |
|---|---:|---:|
| 有效任务合格交付 | 16/16 | 16/16 |
| 无效任务提前拒绝 | 4/8 | 4/8 |
| 输入 token | 33,378 | 44,224 |
| 输出 token | 240 | 240 |

48 次调用均成功解析，所有臂完整报告。**质量增益为 0，输入 token 增加约 32.5%。** 因此不将预测上下文默认加入每次产品对话。合计 78,082 tokens，按本机配置单价估算 ¥0.159，实际账单可能不同。40 个非拒绝动作真实执行登记程序并复核文件。

## 保留失败，再验证修正

首轮 `sealed-boundary-new-empty-group` 中，整体 test 集有数值，但单个分组全空。原观测只有“整个 test 是否全空”，候选错误预测可执行，实际失败，独立验算拒绝交付。原模型、错误预测、异常与文件均保留，没有重写旧测试成绩。

第二轮协议：`df8de6480167f70e9ea49fc24a0bcddcf3289aa30fb235403078fe2fae741782`。

候选补入每个预计保留分组的数值覆盖观测。**特征修正由人工研究判断引导，并非自主发现因果定律。** 三个投影特征为预计没有 test 行、存在全空分组、存在非法数值。按登记清洗顺序投影，不用执行结果，仍需真实执行验证。

逻辑回归头仅用原 **1,280 条训练执行**的失败标签，进行 1,200 步梯度训练，学习率 0.2、L2=0.002。第一轮测试没有进入梯度；它已成为开发发现证据，不能再作未见测试。阈值仅在原 544 条校准执行上选取 0.5；逻辑回归分数未做概率校准。

边界模型摘要：`3de0d2862a3d759b06657ac19140a0945fc4c6bf68ea6feed6de230d295b4e96`。

新封存 40 道任务基于另一个来源 [UCI Iris](https://archive.ics.uci.edu/dataset/53/iris)，CC BY 4.0，引用 Fisher, R. (1936)，DOI [10.24432/C56C76](https://doi.org/10.24432/C56C76)。20 道有效任务包括允许删除空分组的情况；20 道无效任务包括必须保留的空分组、非法数值、缺少 test、未知目标与结构。空值、异常、标识与集合均为受控变换，不是对 Iris 原数据的缺陷判断。

预测先整体保存，再执行三臂各两次，共 240 条臂记录、180 次子进程执行。强制诊断臂也执行被策略拒绝的有界公开输入，检查“若执行会怎样”。

| 结果（按不同任务计数） | 原基础检查 | 学习后的边界 | 强制诊断 |
|---|---:|---:|---:|
| 有效任务交付 | 20/20 | 20/20 | 20/20 |
| 有效任务误拒 | 0 | 0 | 0 |
| 无效任务提前拒绝 | 10/20 | 20/20 | 0/20 |
| 无效任务仍执行 | 10/20 | 0/20 | 20/20 |

这支持新来源下、这些预声明条件中的失败避免效果，不是原本合格任务的质量提升。未知目标/结构由明确范围规则阻断，其余由学习头判断；不能把范围规则全算成模型学习收益。

**特征匹配规则的事后诊断。** 用相同三个细化条件直接构成规则，也达到有效交付 20/20、无效提前拒绝 20/20。该对照是在测试完成后定义，明确标记为探索性诊断，不冒充预注册结果。因此，本轮证据更支持“补足观测能修复边界”，尚未证明训练头比同特征规则更好。

内核增加可选 `csv_group_numeric_coverage` 状态谓词，真实读取分组数值覆盖：每个选中分组至少有一个有限数值，所有非空值可解析，没有匹配记录也阻断。可按 `where` 精确筛选 test 集。它进入现有步骤状态契约路径，失败时在代码生成前停止；不强行用训练替代可直接验算的条件。

重复执行只是确定性稳定检查，不增加独立样本数；两轮各只有一个公开测量来源，任务共享记录，边界经过人工设计。未验证任意工具 API、复杂文档、多模型迁移、真实个人任务流或长期持续改进。

## 十二门与落地

本轮研究审计 **8/12**，阻断版本凭证、质量增益、可靠性和一次性奖励凭证，奖励 0。第二轮失败避免也不越过现有质量奖励门。若未来奖励成本或风险改善，必须在新测试前定义效用和准入，不得事后重写本次规则。

`/utility` 展示完整策略、真实 API 对照、旧反例、新边界和门控阻断。选择两轮公开任务，先看预测、输入、契约，再重新启动程序，检查 CSV、SHA 与独立判据。接口只接受登记任务 ID，拒绝客户端代码、路径、模型权重和证书；写操作复用令牌、并发上限和临时目录隔离，版本不匹配时停止。

原 1,881 项技能自检索、个人球体、明确偏好训练、联网研究和 S1 契约保留。研究模型没有替换正式路由，也未把提问、点击或一次运行当成全体技能正奖励。S1 生产联调仍未完成。
