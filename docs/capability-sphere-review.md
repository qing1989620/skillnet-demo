# 能力球体与可检查的状态变化

2026-10-12。本次将研究启发落实为可演示、可复核的能力，没有将理论设想包装成已完成的算法。

## 核验与取舍

核验范围为原始论文摘要和官方仓库，不是完整创新查新或上游实验复现。

| 来源 | 启发 | 产品落地及边界 |
|---|---|---|
| [SkillNet](https://arxiv.org/abs/2603.04448) / [Fabric 官方仓库](https://github.com/zjunlp/SkillNet-Fabric) | 关系、适用条件与任务局部化共同服务少量技能选择；更大候选池不必然得到更好组合 | 保留问题驱动检索、少选/空选；球体展示真实目录，任务层区分采用与实际步骤 |
| [ASSAY](https://arxiv.org/abs/2606.15390) | 技能作用随任务变化，相关性不能替代贡献测量 | 不用节点尺寸暗示成功概率；参与不等于正贡献，不统一发奖 |
| [SIGIL](https://arxiv.org/abs/2607.27309) | 自然语言说明不自动等于忠实执行 | 将声明与实际输入输出、独立检查分开；没有声称完成 typed IR 编译器 |
| [SkillHEX](https://arxiv.org/abs/2608.05628) | 单次失败可能对应多个原因，修复需要可检验诊断 | 展示声明的失效边界，保留真实修复轨迹；不从一次失败自动改写适用域 |
| [SEA](https://arxiv.org/abs/2607.00871) | 自评、自修改需要独立约束和可审计准入 | 沿用十二门 AND 与版本奖励；未实现该论文的 anytime-valid 证书 |

“因果能力算子 → 行为等价 → 最小能力基 → 能力可达域”值得继续研究，但当前没有足够干预实验和跨环境探针。1,881 个技能不是 1,881 种已验证独立能力；证据缺口也不是能力缺口。

## 球体的语义

- 首页、内核现场的检索阶段、完整星图共用 Canvas 组件，无新增外部依赖。全部节点来自当前目录，确定性等面积球面布局只服务浏览，不代表语义距离、因果距离或学习出的能力几何。
- 关系弧来自真实关系表。默认省略非聚焦的相似关系笔画以控制密度，聚焦后显示邻域；不增加假关系。
- 支持旋转、缩放、搜索定位、领域/关系/邻域/演化来源筛选。搜索按钮是键盘替代入口。方向键旋转、加减键缩放、空格暂停、Home 重置。
- 任务层来自执行时采用/步骤记录，底图标明为当前目录。历史技能不在当前库时单独计数；通用步骤不伪装成技能节点。
- 颜色表示领域，金环表示演化来源，任务状态环表示真实步骤状态。它们都不代表技能贡献或通过晋级。
- 七阶段、历史事件回放、暂停/定位/倍速、DAG 和跨轮文件追问保留。首页球体平滑过渡到执行 DAG；同一技能的多个步骤按步骤 ID 分开，通用步骤也可见。
- 动画上限约 30 帧/秒，DPI 上限 2，关系弧预计算；离屏和隐藏标签页取消动画，减少动态效果默认静止；组件可完整销毁清理。

## 声明与实际观察

`GET /api/skill/{name}` 新增 `passport`：当前版本 SHA-256、适用条件、输入、预期产物、陷阱、验收条件和环境。它是声明，历史调用率不会为当前版本生成成功概率或因果认证。社区资源依旧按需读取，不自动执行。

`GET /api/runs/{id}/capabilities` 新增只读 `skillnet-transitions-v1`：

1. 在读取时复用证据包重新计算物理文件的 SHA-256 和大小。
2. 用物理文件名、指纹与生产步骤绑定真实消费的输入；错误或重复绑定保留未知。
3. 连接实际输入 → 登记产物 → 程序检查 → 独立结果判据。完成、文件完整、必要检查通过且冻结验收范围受支持，才能呈现本步骤限定范围观察。
4. 列出未绑定技能、缺少独立判据、版本未记录、输入/产物未核实和未执行计划。不会自动改写技能、奖励或排序。
5. 包含来源证据包摘要与自身摘要。服务令牌及 S1 签名项目权限覆盖此端点；SDK `get_capabilities` 验证报告摘要、Run ID 与来源摘要格式。

报告使用历史记录，不拿今天的技能声明为旧任务补理由。摘要证明内容一致，不是外部签发的能力证书。文件交接不证明技能语义兼容，更不等于因果技能代数。

六页面共用直接可见的逐步输入/产物展示。需要核对时打开报告，重新检查文件并下载 JSON；球体节点详情展示当前能力声明与失效边界。

## 本机实测

复用真实运行 `f11ad204-20261010-110841-6d42`，本轮只读，没有额外付费调用：

- 3 步、5 个文件、5 次文件交接；5/5 交接指纹一致。
- 清洗、指标计算分别有 8/8、10/10 独立数字结果检查。
- 图表与报告没有独立质量判据，保持未确认。全任务原有 20 项检查中的图像存在/报告模拟标记不升级为本步质量分。
- 2 个证据缺口：1 个通用步骤未绑定技能，1 个步骤缺少独立结果判据。它们不证明任务无法完成。
- [原始报告](evidence/capability-transitions.json) 不改变原运行或原证据包。
- 六页面和三项球体资源 9/9 HTTP 200，页面版本 `2026-10-12.sphere.1`。

自动检查覆盖球面几何、1,881 节点容量、深度拾取、旋转/点击区分、暂停、离屏与销毁、稀疏步骤索引、循环保护、文件绑定篡改、重复登记、冻结范围缺失、签名项目隔离、SDK 摘要和非有限数拒绝。全套结果见 PR。

回归时另外发现并修复语义缓存的并发临时文件冲突和 Windows 替换锁问题：临时文件改为唯一名称，缓存不可写时仍使用已计算的内存索引，损坏/形状错误的缓存重新计算。并发自检现在捕获写线程异常并检查线程停止，避免后台线程失败仍报告通过。

**视觉验收未完成。** Windows computer-use 工具因无法可靠识别浏览器当前网址停止本轮控制，没有获取新版截图。自动检查不能替代浏览器布局、字体、触摸手感和帧率验收。S1 线上联调也未验证，保持 Draft。

## 后续研究如何获得证据

先冻结一个任务族、有限探针环境和独立验证器，进行有/无技能的同预算干预对照，记录条件、输出、成本和失败模式，再估计条件化效果。行为等价需要多环境探针；最小能力基与可达域需要明确组合语义及覆盖目标。球体未来可以承载这些结果，当前不会绘制未经测量的成功概率或能力边界。
