# 从能力星球，走到同一次任务的证据

研究内核移植修复提交 `bdcf10e23283189f70448154d256db9900a2af82` 的 push/PR CI 均 5/5 通过后，再实施本轮展示交互。研究结果、限制与复现见 [frontier-results.md](frontier-results.md)，该阶段 CI 见 [frontier-ci.json](evidence/frontier-ci.json)。以下是展示与导航改进，不增加能力学习或奖励。

- 首页真实领域按钮可以聚焦并还原球体，显示真实目录计数。搜索渐进展开，支持方向键、Enter 与关闭恢复；选中技能读取当前用途、来源边界与登记关系。摘要位于球体下方，保留背景、原控件、七阶段回放和自检索。
- 星图关系按声明方向区分“依赖谁”和“被谁依赖”，关系卡与筛选同步。沿关系探索可返回上一个技能，继续保留运行与步骤上下文。组合和相似关系不冒充执行依赖或行为等价。
- 任务球体可以选择原始步骤编号，查看实际输入登记、产物、必要检查与前后条件。通用步骤明确没有技能高亮；未记录的独立判据保持未知。跨轮输入读取当前运行中的复制文件，原运行 ID 仅用于说明来源。
- 共用技能卡增加“选择 → 执行 → 复核”的折叠证据。能力护照分别呈现历史执行 SHA 和当前技能声明；球体、护照、步骤与运行详情的链接保留 `run / skill / domain / step`，无效步骤回退到首个真实步骤。异步失败、旧响应、身份不匹配与跨运行相同 idx 不混入当前证据。

实际 IAB 桌面与手机宽度观察见 [exploration-ui-observations.json](frontend-audit/exploration-ui-observations.json)。验证了领域选择、键盘搜索、护照、关系方向与计数、步骤选择、手机层次恢复、真实回放技能卡及运行深链接。浏览器发现任务面板与筛选条重叠；保留 v10 失败截图，v11 重测位置不再重叠，展开筛选或手机技能详情会暂时隐藏任务面板，关闭后恢复原步骤和展开状态。

11 组 Node 检查覆盖原有回归与新增真实模块控制 DOM 逻辑。其中新首页检查包括 120 次筛选循环不增加监听、超时/重试、陈旧响应、关闭/DAG/页面离开；新星图检查包括关系方向、过滤、返回栈、非连续 idx、通用/缺失技能、输入文件归属及上下文链接。控制 DOM 证据与原生浏览器观察分别记账。

这些是有限的实际交互证据，不意味着 16 个完整父视图、全部错误网络路径、屏幕阅读器、200% 缩放、真机触摸、性能预算或 S1 生产接入已经验收。没有新增付费模型调用，也没有更改正式技能库或研究执行器。
