# 真实联网研究与在线技能补充

此前人物调研方案要求联网，但执行器的全局提示允许“缺数据就模拟”，实际没有搜索工具；模型生成了模拟身份命中，再凭假定声称环境无法联网。此次将网络采集放到宿主工具层，分析代码消费冻结证据，禁止用模拟人物、机构、论文或链接填补事实缺口。

## 实际链路

`当前问题 → 公共检索词 → Tavily / 学术元数据接口 → 安全原站抓取 → 冻结来源索引与快照 → 技能分析 → 宿主逐行核验 → 带来源的回答`

- 通用搜索使用 Tavily；学术搜索补充 Crossref、Europe PMC。Tavily 的 [官方 keyless 模式](https://github.com/tavily-ai/tavily-python#keyless-mode) 无需注册即可试用，但不保证匿名额度或服务可用性。设置 `TAVILY_API_KEY` 可使用自己的账户；`SKILLNET_WEB_ENABLED=false` 关闭采集。配置接口不做联网探测，也不返回密钥。
- 直接抓取验证所有 DNS 地址，实际连接固定已验证的公共 IP；HTTPS 仍验证原主机证书。每个重定向重新核验，拒绝私网、元数据地址、URL 凭据及非法端口；不携带环境代理或 cookies，限制时间、压缩正文和字节数。
- 来源记录包括原始/最终 URL、真实 HTTP 状态、时间、SHA-256、快照文件、正文与失败原因。原站无法打开时，可尝试第三方正文提取，明确标记 `provider_extract`，原站 HTTP 保持未知。搜索摘要不能直接当核验结果。
- 搜索最多 6 条候选、抓取并发 3；采集阶段期限 42 秒，在线技能补充另有最多 18 秒总预算。每个步骤继续受任务预算和取消检查约束。单个有界请求结束前取消可能有延迟。
- Docker 分析环境保留 `--network none`；宿主搜索凭据不进入分析代码。本机子进程演示不构成恶意代码隔离，生产应使用 Docker 与独立 Worker。

公共来源索引为 `web_sources.json`；引文唯一语料是其 `sources[].text`。`web_snapshot_*.txt` 保存原始 HTTP 实体字节，可能包含 HTML，供追溯使用，不能由模型自行剥标签后重新拼接“原文”。CSV 台账通过 `source_id,evidence_url,claim,quote` 关联来源。

## 验收与失败边界

宿主重新核对索引和快照 SHA、来源 ID 与 URL、CSV 结构及正文连续摘录。摘录原始长度限 12–500 字，去掉空白和不可见格式字符后仍须至少 12 字，空白填充不能通过。验收从冻结实体重新提取正文，不能靠改写内存中的 `text`、复制假的 SHA、重复表头或引用其他来源绕过。**摘录存在只证明出处匹配，不证明 claim 的逻辑蕴含、来源诚实或科研结论为真。** 最终联网回答仅使用已绑定原文，不能把执行器打印的事实直接当依据。

人物任务第一步必须提交身份台账；缺失、空表、未知、引用错绑和仅提交普通引用表均不能放行著作聚类。后续步骤强制依赖身份门，模型声明并行根步骤也不能绕过。姓名、机构、领域须在当前引用及至少两个不同站点的有限正文范围内得到支持；子域不当独立站点，显式否定和远距离共现不放行。该有限规则仍不等于完整的实体关系推理或普遍身份证明。同名歧义保留未知，先交付来源与缺口，不能虚构生平。

错误的“按 CSV 检查 JSON”在规划边界触发最多一次修复，不静默删除必要验收；仍错误时记录剩余问题，运行门继续拒绝。明确允许的模拟数据分析保留支持，但人物等外部事实不能模拟。

## 在线补充 Skill

本地缺少相关供给、人物消歧或用户明确要求补充技能时，执行通用能力词的 GitHub 站点搜索。候选必须有明确 `SKILL.md` 路径，固定仓库提交，核对正文 Git blob 与 SHA-256、同版本根许可并记录星数。仅采纳有已知许可的最多两个候选。

候选作为 **本次运行的隔离方法参考**，进入本次规划与步骤选择；不安装脚本，不执行远程代码，不写正式技能库，不分配奖励。星数只反映仓库关注度，不能证明技能质量。目录内许可覆盖与外部依赖尚未完全解析，因此不能自动安装。正文仍是第三方不可信资料。

## API 与呈现

`POST /api/runs` 与 S1 SDK 新增 `web_mode: auto | on | off`，默认 `auto`。`on` 主动采集；`off` 关闭本次新采集。明确禁止联网、保密资料或缺少公共检索词时仍不外发。代码块、分隔数据、邮件、手机号、凭据和 URL 查询串不作为搜索词；混合数据任务改用受限方法关键词。此预处理不能识别所有自然语言秘密，敏感业务应选 `off` 或部署组织自己的搜索服务。

工作台提供模式选择；首页内核现场显示网络事件；运行详情与共享证据组件展示来源、HTTP、快照、逐行核验和隔离候选。S1 证据包同步该投影，仍不代表 S1 生产联调已完成。新话题不自动携带前轮文件，明确追问或指定 `artifact_refs` 才复用；每步仅挂载声明的输入，旧式未声明计划保留兼容行为。

## 本轮实测

- 公开 Crossref 任务：真实模型执行 2/2 步，6 条原站抓取记录 HTTP 200（其中两条为同一实体的带/不带尾斜杠 URL；不是六个独立站点），31 条台账检查均绑定到正文，10 次模型调用，¥0.1766，70.0 秒。后续 URL 规范化已合并尾斜杠重复。行检查数量包含多步台账，不是 31 条独立科学事实。
- 同轮前两次公开运行分别发现自行剥 HTML 导致引文错配、把 JSON 当 CSV 的规划错误；门禁阻断下游，之后统一语料并加入有界重规划。保留失败指标，不只展示成功运行。
- 原同名人物任务真实联网取得了原站快照与提供方摘录，并找到隔离在线技能；身份仍未知，下游聚类 0 次执行。私有问题、运行台账和正文不进入公开证据。
- 在线技能模块真实发现 `garrytan/gbrain` 的 `academic-verify`，固定提交和 MIT 许可；这证明发现通道可用，不证明它改善任务质量。
- 离线测试验证来源篡改、SSRF、限额、禁网、引用错绑、空身份门、历史隔离和实际子进程输入传递。浏览器仅核验指定桌面/手机断点及网络证据交互，不宣布全站或生产验收通过。

公开来源元数据与运行指标见 [web-network-smoke.json](evidence/web-network-smoke.json)。原始抓取页面及模型产物保留本地运行目录，不随仓库再分发。原有能力边界实验及其冻结来源没有修改；联网成功不能给技能网络统一加分。

可显式执行 `python tools/web_network_smoke.py --network --discover` 复测公开搜索、来源快照、逐行摘录、私网拒绝和隔离技能发现；该命令不调用 LLM，不计入离线 CI。浏览器验证与截图范围见 [web-ui-observations.json](frontend-audit/web-ui-observations.json)，本轮代码指纹单独保存在 `web-source-manifest.json`，不覆盖上一轮前端审计证据。
