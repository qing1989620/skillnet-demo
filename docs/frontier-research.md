# 能力边界研究：把“没找到”与“当前模型不可达”分开

研究核验日期：2026-10-12。本文是本轮实现前的研究协议与接口建议；其中实验假设和成功标准不代表实验已经成功。实际结果须由单独冻结的协议、执行记录和独立判据报告支持。

## 一手资料重新核验

本轮主动检索并阅读下列原论文相关方法部分，不把用户长图中的方向名称当成已有实现或已成立的理论。

| 来源与阅读范围 | 原方法支持的结论 | 本项目采用与限制 |
|---|---|---|
| [Fikes & Nilsson，STRIPS，1971，2.1–2.2、3](https://ai.stanford.edu/~nilsson/OnlinePubs-Nils/PublishedPapers/strips.pdf) | 操作需要满足前置条件；世界模型通过 add/delete 列表更新；计划是达到目标的操作序列。 | 可在固定有限状态词表上做组合搜索。但搜不到计划的含义由状态抽象、操作全集和搜索完整性限定，不能外推成“智能体没有这种能力”。 |
| [Sutton、Precup & Singh，Options，1999，2、3](https://people.eecs.berkeley.edu/~russell/classes/cs294/f05/papers/sutton%2Bal-1999.pdf) | 跨多步的闭环策略可以作为高层动作参与学习与规划。 | 将已注册可执行技能视为宏观动作有理论亲缘；自然语言说明、静态效果集合和少量成功记录并没有建立完整的 option transition model。 |
| [Angluin，Learning Regular Sets from Queries and Counterexamples，1987，2.1–2.2、4](https://homepages.math.uic.edu/~lreyzin/papers/angluin87.pdf) | 查询回答形成观测表，反例促使假设细化；精确学习依赖等价查询，采样替代时结论带分布、精度和置信条件。 | 有限探针一致应命名为观测一致；新反例可拆分分组。手工挑选几个 probe 不能借用该论文的普遍等价或 PAC 保证。 |
| [Muškardin 等，AALpy，2022，2.1、2.4](https://link.springer.com/article/10.1007/s11334-022-00449-3) | 实际系统的等价查询常通过一致性测试近似；执行输出差异是反例，测试策略侧重尽快发现反例。 | 主动选择能区分现有假设的输入；阻断、异常、缺少输出都不能当作两个实现相等的证据。 |
| [Catanach & Das，Metrics for Bayesian Optimal Experiment Design under Model Misspecification，2023，I、II-D、III](https://arxiv.org/html/2304.07949v1) | 信息增益依赖用于预测数据的模型；模型失配时，高预期增益可能继续采集质量不佳的数据。 | 本轮有限假设分歧分数必须暴露先验、假设集与噪声假定。保留随机或留出探针检查未建模错误；不把熵下降直接称为真实能力增长。 |
| [Contract2Tool，2026，III–V、IX](https://arxiv.org/html/2606.07904v1) | 规范化 requires/effects 可以帮助工具过滤，但固定词表与受控工具环境限制外推；契约误差会造成过度或不足过滤。 | 声明转换与实际执行观测分账，测量误阻断和错误放行。该论文受控模拟结果不是本项目真实执行收益的证据。 |

这里的工程推论是：先建立一个可复验的有限能力模型，再研究它的边界、反例与增量。不能反过来把 LLM 填写的声明当作已证实的世界模型。

## 可计算的研究对象

第一阶段限定为公开模拟的 CSV 科研任务族。固定词表、输入语义、执行环境、代码版本、目标集合、成本与最大搜索资源。技能实现只允许宿主登记的可执行程序，不执行网上下载的任意技能代码；千余条技能文档仍用于原有检索。

抽象状态为 `z ∈ {true, false, unknown}^F`。事实必须绑定输入/输出 SHA、谓词和执行器版本。`unknown` 不等于 `false`，后续实测可以将其变为 true 或 false。操作记录输入契约、条件化效果声明、失效/删除集合、执行器指纹与证据来源。涉及同名文件覆盖时，旧版本事实必须失效；不允许简单地把新旧效果永远做集合并集。

声明模型 `M_declared` 用于提出路径。实际执行记录 `D_observed` 用于反驳或支持该路径。二者分别保存，界面分别显示“声明可达”和“本次执行已复核”。有限探针覆盖不到的输入仍没有证明。

## 五种不能混淆的结论

| 状态 | 允许输出的证据条件 | 面向用户的含义 |
|---|---|---|
| `reachable_declared` | 在明确模型中找到满足目标的路径，返回所用声明及版本 | 已找到一个待执行验证的组合 |
| `retrieval_miss` | 候选集无路径，但完整登记库搜索有路径，且两次使用同一状态/语义 | 当前检索漏掉了所需提供者；不能说能力缺失 |
| `unreachable_closed_world` | 完整有限模型、已知初态、受支持且完整的转换、全状态搜索到固定点，无截断，目标仍未到达 | 仅在这个模型与登记操作全集内不可达 |
| `evidence_insufficient` | 未知初态、缺少契约、未经验证的关键效果或无法解释的输入性质会影响结论 | 需要补观测或补模型，当前不能判断 |
| `search_truncated` | 深度、状态数、时间或成本预算耗尽且仍有待扩展状态 | 搜索没有完成；预算不足不构成不可达证明 |

若模型只是完整枚举的声明而非完整真实转换，`unreachable_closed_world` 必须附 `model_kind=declared` 与“声明模型内不可达”。若只搜索到深度 d，最多可报告“未发现长度 ≤ d 的计划”，不能写“闭包不可达”。未取得全库清单时不能判定检索漏召回；没有候选也不能自动生成技能负贡献。

实现可使用两层搜索：先查检索候选，再查固定登记全集。搜索为确定性 BFS，状态去重，返回路径、扩展数、未满足目标、截断原因、模型 SHA、闭世界范围与证据缺口。对于第一阶段纯单调正谓词算子，可计算有限固定点；若含删除、互斥或条件效果，必须搜索真实状态而不能只做正事实闭包。

## 主动探针：降低哪一种不确定性

将待验证实现/效果假设集合记作 `H`。每个候选输入 `q` 由每个假设给出可区分的预测输出。均匀先验、确定性预测且观测无噪声时，按预测分区计算：

```
p(y | q) = |{h ∈ H: prediction(h,q)=y}| / |H|
score(q) = -Σ_y p(y | q) log2 p(y | q)
```

这是**当前有限假设集的预测分歧熵**，在上述假设下等于预期假设熵下降。实际执行 q 后，仅用独立读取的输出更新版本空间；程序超时、谓词不支持、解析失败均记 unknown，不能强行排除假设。若实际输出不属于任何预测，返回 `model_mismatch`，保留反例并扩展假设集，不能从空集合宣布确定性 100%。

候选输入应包含独立定义的阈值边界、缺失、单位/表头变化、重复、分组泄漏和环境漂移。模型预测不能调用隐藏 oracle 来排序探针，否则“主动选择”偷看了真值。若一个假设根本不会预测候选输入，相关 score 也为 unknown。成本不同则同时报告信息/成本，但不暗示全局最优。

首批将固定顺序、均匀随机和分歧优先作对照，同样的调用预算与候选输入。随机基线使用预注册多个种子，报告全部种子与分布；不能只选一个不利种子。至少保留一组不用于选择或修复的留出输入，验证未建模错误。

## 观测一致与有限能力基

两个实现只有在共同成功执行、独立条件验收通过的同一探针上，才可以比较规范化后的语义输出。哈希相同可证明那份字节相同；它不证明全部行为相同。探针不足、共同失败或 unknown 不能缩成“等价技能”。分组返回共同有效输入数、不同输出的反例和比较语义版本。

能力基第一阶段只求**冻结有限目标集合上的最小登记子集**。在很小的操作集上穷举子集，并重新规划/实测预注册目标；验证覆盖保持、成本与失效事实。若只是贪心覆盖，应叫“压缩候选集”而非最小基。即便穷举找到最小子集，也仅对这组目标和模型成立，不能对整个 SkillNet 的开放任务空间成立。

只按文本相似删技能会删掉有效替代实现；只按少量当前任务删技能又可能丢失未来任务能力。因此研究结果先放实验注册表，不能据此自动删除正式技能、改排序或发奖。

## 可证伪假设与实验矩阵

| 假设 | 对照与独立判据 | 失败标准 |
|---|---|---|
| H1：完整小模型可以区分检索漏召回、模型内不可达和证据不足 | 主动移除候选、移除全集唯一提供者、未知初态/契约、预算截断；与独立枚举状态图和预注册标签逐项比较 | 任一 unknown 或截断被称不可达，或未完整扫描被称检索漏召回，即否决该结论分类 |
| H2：分歧优先更快找到已建模反例 | 同预算下比较固定序、随机多种子、分歧优先的首次反例调用数和版本空间；排序程序不能访问隐藏实现输出 | 无稳定收益则保留无收益结果；不得把构造的单个好例子宣称通用收益 |
| H3：新增提供者会扩大真实可完成目标集 | 同一输入/SHA、目标/oracle、环境，执行旧模型与加一操作后的规划；统计独立验收的新增目标而非节点数 | 新路径只在声明里可达、执行不通过，或加入操作破坏旧目标，不能算边界扩张成功 |
| H4：观测分组可被新反例撤销 | 两个正确实现、一个 `>=`→`>` 缺陷实现先测普通输入，再测边界；独立 Decimal 参考评定 | 把共同阻断当一致、漏掉边界差异、自动合并正式技能，均失败 |
| H5：有限子集压缩不损失预注册覆盖 | 穷举小注册表，与保留全部操作的真实验收覆盖和成本对比；另有留出目标揭示范围限制 | 训练目标覆盖降低，或未穷举却称最小，或把留出退化隐藏，均失败 |

实验需冻结协议 SHA、源码 SHA、输入 SHA、候选顺序/随机种子、环境、oracle 版本、预算和指标。每次子进程保存退出码、时长、实际输出、前后条件与独立结果；同时保存失败和反例。不以 pytest 通过冒充研究收益。发现错误可以修改下一版方法，但必须保留原版失败及协议差异，不能用修复后的结果覆盖失败。

## 项目落地与对领导的呈现

建议接口包含 `version / scope / model_sha256 / state / candidate_result / registry_result / path / gaps / search_complete / truncation / evidence_level`。主动探针包含 `hypotheses_sha256 / prior / predictions / score_kind / score / cost / observation / surviving_hypotheses / counterexample`。执行证据沿用当前 state kernel 的文件指纹与程序检查，不复制出一套不可核对的指标。

先在“研究实验室”展示：输入目标 → 候选不足 → 全登记模型定位漏检或有限缺口 → 选择区分性探针 → 真实执行 → 反例撤销宽泛声明 → 加入经复验操作 → 同目标实测可达。球体突出当前目标所需的少数节点、缺口与已观测边，不把全图连线数量当作能力增长。

只有实验在预注册任务和独立判据上通过，才把相应机制接入当前产品路径；实验元数据不得自行开启正式策略更新。现有十二道 AND 奖励门仍独立生效。公开模拟任务的有界结果可成为可演示的工程亮点，但还不是任意科研任务的因果世界模型、全球最小技能基、普遍行为等价证明或 S1 生产联调成果。
